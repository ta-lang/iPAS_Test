## 📌 L22101 敘述性統計與資料摘要技術

### 1. 集中趨勢指標 (Measures of Central Tendency)

| 指標 | 定義與公式 | 特性與極端值敏感度 | 適用資料類型 |
|---|---|---|---|
| **算術平均數 (Mean, $\bar{X}$)** | $\bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i$ | **極易受極端值/離群值影響** | 對稱分佈的連續數值資料 |
| **中位數 (Median, $M$)** | 排序後位於中間 50% 的數值 | **對極端值具高穩健性 (Robust)**，不受離群值干擾 | 偏態分佈（如薪資、房價）、具離群值資料 |
| **眾數 (Mode)** | 出現次數最高的數值 | 不受極端值影響，可能有雙眾數或無眾數 | 類別資料 (Categorical)、離散資料 |

### 2. 偏度 (Skewness) 與 三者大小關係 [🎯 常考極高頻]
* **常態分佈 / 對稱分佈 (Symmetric)**：
  $$\text{Mean} = \text{Median} = \text{Mode} \quad (\text{偏度 } = 0)$$
* **右偏分佈 / 正偏態 (Right-Skewed / Positively Skewed)**：
  * 長尾巴朝向右側（高數值端，少數極大值將平均數往右拉高）。
  * 數值大小順序：**$\text{Mean} > \text{Median} > \text{Mode}$**
* **左偏分佈 / 負偏態 (Left-Skewed / Negatively Skewed)**：
  * 長尾巴朝向左側（低數值端，少數極小值將平均數往左拉低）。
  * 數值大小順序：**$\text{Mode} > \text{Median} > \text{Mean}$**

### 3. 離散程度指標 (Measures of Dispersion)
* **全距 (Range)**：$\text{Range} = X_{\max} - X_{\min}$（只看兩端，極易受極端值影響）。
* **四分位距 (Interquartile Range, IQR)**：
  $$IQR = Q_3 - Q_1$$
  * 代表中間 50% 資料的分散寬度，對極端值具極高穩健性。
  * **箱形圖離群值判定界限**：
    $$\text{離群值界限} = [Q_1 - 1.5 \times IQR, \; Q_3 + 1.5 \times IQR]$$
* **變異數 (Variance) 與 標準差 (Standard Deviation)**：
  * **母體變異數**：$\sigma^2 = \frac{1}{N}\sum_{i=1}^{N}(X_i - \mu)^2$
  * **樣本變異數**（使用無偏估計，分母除以 $n-1$ 自由度）：
    $$s^2 = \frac{1}{n-1}\sum_{i=1}^{n}(X_i - \bar{X})^2$$
  * **標準差**：$s = \sqrt{s^2}$，與原始資料同單位，代表平均離散距離。
* **變異係數 (Coefficient of Variation, CV)**：
  $$CV = \frac{s}{\bar{X}} \times 100\%$$
  * 無單位純數，用於比較「**單位不同**」或「**均值差距懸殊**」的兩組資料離散程度。

## 📌 L22102 機率分佈與資料分佈模型

### 1. 常見機率分佈類型

| 分佈名稱 | 型態 | 核心參數 | 期望值 $E(X)$ | 變異數 $Var(X)$ | 典型應用場景 |
|---|---|---|---|---|---|
| **二項分佈 $B(n, p)$** | 離散 | 試驗次數 $n$, 成功機率 $p$ | $np$ | $np(1-p)$ | 丟 $n$ 次硬幣正面次數、點擊廣告人數 |
| **卜瓦松分佈 $\text{Poisson}(\lambda)$** | 離散 | 單位時間/空間平均發生次數 $\lambda$ | **$\lambda$** | **$\lambda$** (均值等於變異數) | 每小時網站訪問數、瑕疵點數量、客服進線數 |
| **常態分佈 $N(\mu, \sigma^2)$** | 連續 | 平均值 $\mu$, 標準差 $\sigma$ | $\mu$ | $\sigma^2$ | 身高、測量誤差、考試成績 |

### 2. 標準常態分佈 ($Z$ 分數) 與 經驗法則 [🎯 計算必考]
* **標準化公式 ($Z$-Score)**：
  $$Z = \frac{X - \mu}{\sigma}$$
  * 代表該數值距離平均值有「幾個標準差遠」；若 $Z > 0$ 表示高於平均，$Z < 0$ 表示低於平均。
* **經驗法則 (Empirical Rule / 68-95-99.7 法則)**：*僅適用於常態（鐘形）分佈*
  * 約 **68.27%** 的資料落在 $\mu \pm 1\sigma$ 區間內。
  * 約 **95.45%**（實務常取 95%）的資料落在 $\mu \pm 2\sigma$ 區間內。
  * 約 **99.73%** 的資料落在 $\mu \pm 3\sigma$ 區間內。
* **柴比雪夫不等式 (Chebyshev's Inequality)**：*適用於「任何任意形狀」的分佈*
  * 至少有 $1 - \frac{1}{k^2}$ 的資料落在 $\mu \pm k\sigma$ 區間內 ($k > 1$)。
  * 當 $k=2$：至少有 $1 - 1/4 = 75\%$ 的資料落在 $\mu \pm 2\sigma$ 內。
  * 當 $k=3$：至少有 $1 - 1/9 \approx 88.89\%$ 的資料落在 $\mu \pm 3\sigma$ 內。

### 3. 中央極限定理 (Central Limit Theorem, CLT) [🎯 常考]
* **定理核心**：不論母體母體呈何種分佈（偏態、均勻、雙峰皆可），只要隨機抽樣的樣本數 $n$ 充分大（實務通常取 $n \ge 30$）：
  * 樣本平均數 $\bar{X}$ 的抽樣分佈會**趨近常態分佈**。
  * 抽樣分佈平均值等於母體平均值：$E(\bar{X}) = \mu$。
  * 抽樣分佈標準差稱為**標準誤 (Standard Error, SE)**：
    $$\sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}}$$

## 📌 L22103 假設檢定與統計推論

### 1. 虛無假設 ($H_0$) 與 對立假設 ($H_1$)
* **虛無假設 ($H_0$)**：代表「無效、無影響、無顯著差異、維持現狀」的假設，必須包含等號（$=, \le, \ge$）。
* **對立假設 ($H_1$ 或 $H_a$)**：研究者試圖證明具有實質差異、新策略有效的假設（$\ne, >, <$）。

### 2. 型 I 錯誤 ($\alpha$) 與 型 II 錯誤 ($\beta$) [🎯 常考極高頻]

| 決策 \ 實際情況 | $H_0$ 實際上為「真」 | $H_0$ 實際上為「假」 |
|---|---|---|
| **拒絕 $H_0$** | **型 I 錯誤 ($\alpha$, 偽陽性 False Positive)**<br/>（沒病判有病、沒作弊判作弊） | **正確決策 ($1 - \beta$, 檢定力 Power)**<br/>（有病成功抓出） |
| **未拒絕 $H_0$** | 正確決策 ($1 - \alpha$, 信心水準 Confidence) | **型 II 錯誤 ($\beta$, 偽陰性 False Negative)**<br/>（有病判沒病、放走罪犯） |

* **顯著水準 (Significance Level, $\alpha$)**：允許犯下型 I 錯誤的最大上限，最常見為 $\alpha = 0.05$。
* **權衡關係**：在樣本數固定下，降低 $\alpha$ 必然會導致 $\beta$ 上升。唯一同時降低 $\alpha$ 與 $\beta$（提高檢定力）的方法是**增加樣本數 $n$**。

### 3. $p$ 值 (p-value) 的決策準則
* **統計定義**：當虛無假設 $H_0$ 成立的前提下，觀察到目前樣本檢定統計量或更極端情況的機率。
* **決策判準**：
  * **$p < \alpha$ (如 $p < 0.05$)**：檢定結果具**統計顯著性**，**拒絕 $H_0$**，接受 $H_1$。
  * **$p \ge \alpha$**：證據不足以否定現狀，**無法拒絕 (Fail to reject) $H_0$**。

### 4. 常見檢定工具選型速查表

| 檢定名稱 | 適用情境與資料型態 | 範例 |
|---|---|---|
| **單樣本 $t$ 檢定** | 連續變數，檢定樣本均值是否等於某特定基準值（母體標準差未知，小樣本） | 檢驗某批燈泡平均壽命是否為 1000 小時 |
| **獨立雙樣本 $t$ 檢定** | 連續變數，比較兩獨立群體之平均數是否有顯著差異 | 比較新舊網頁版本 (A/B 測試) 之使用者平均停留時間 |
| **配對樣本 $t$ 檢定** | 連續變數，比較同組受試者處理前與處理後 (Before/After) 之均值差 | 員工參加 AI 培訓前後之測驗成績差異 |
| **ANOVA (變異數分析)** | 連續變數，**比較三組或以上獨立群體**之平均數是否有差異 | 比較北、中、南三區門市的平均客單價差異 |
| **卡方檢定 ($\chi^2$)** | **類別變數**，檢定兩類別變數間是否獨立或配適度 | 檢定「性別」(男/女) 與「購買意願」(是/否) 是否相關 |

## 🐍 Python 高頻實戰程式碼與常考考點

在歷屆試題與實務題組中，常考查使用 Python 進行敘述性統計運算與統計分佈機率計算：

### 1. Pandas 與 Numpy 敘述統計運算
```python
import numpy as np
import pandas as pd

# 讀取資料
df = pd.read_csv('driver_daily_stats.csv')

# 考點 1：取得單一欄位常用敘述性統計（mean, 50%/中位數, max 等）
stats = df['daily_earnings'].describe()[['mean', '50%', 'max']]
print(stats)

# 考點 2：四分位距 (IQR) 與離群值過濾實作
Q1 = df['daily_earnings'].quantile(0.25)
Q3 = df['daily_earnings'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

# 篩選離群值
outliers = df[(df['daily_earnings'] < lower_bound) | (df['daily_earnings'] > upper_bound)]
```

### 2. Scipy 機率分佈與 PMF / CDF 計算
* **卜瓦松分佈 (Poisson)**：單位時間內發生 $k$ 次的機率
```python
import numpy as np
from scipy.stats import poisson

lambda_poisson = 5  # 平均每小時發生 5 次瑕疵
k = 5               # 恰好出現 5 次瑕疵

# 考點：pmf (機率質量函數，求單點機率 P(X = k))
prob_exact_5 = poisson.pmf(k, lambda_poisson)
print(f"恰好出現 5 次的機率: {prob_exact_5:.4f}")

# 考點：cdf (累積分配函數，求累積機率 P(X <= k))
prob_lte_5 = poisson.cdf(k, lambda_poisson)
print(f"出現 5 次或以下的累積機率: {prob_lte_5:.4f}")
```

* **常態分佈 (Normal Distribution)**：
```python
from scipy.stats import norm

mu = 100
sigma = 15

# 計算累積機率 P(X <= 130)
prob = norm.cdf(130, loc=mu, scale=sigma)
# 計算雙尾經驗區間 [70, 130] 之機率
prob_interval = norm.cdf(130, loc=mu, scale=sigma) - norm.cdf(70, loc=mu, scale=sigma)
print(f"常態分佈涵蓋比例: {prob_interval:.4f}")  # 約 0.9545
```

## 🧮 歷屆核心計算題範例精解

### 範例 1：標準差與經驗法則計算
> **題目**：某 AI 演算法推論延遲呈常態分佈，平均值 $\mu = 100\text{ ms}$，標準差 $\sigma = 15\text{ ms}$。請問約有多少比例的推論延遲落在 $70\text{ ms}$ 到 $130\text{ ms}$ 之間？
* **解析**：
  1. 計算下界 $Z$ 分數：$Z_1 = \frac{70 - 100}{15} = \frac{-30}{15} = -2$
  2. 計算上界 $Z$ 分數：$Z_2 = \frac{130 - 100}{15} = \frac{30}{15} = +2$
  3. 依據常態分佈之經驗法則，$\mu \pm 2\sigma$ 涵蓋約 **95.45%**（或約 **95%**）的資料。

### 範例 2：四分位距與離群值判斷
> **題目**：某組伺服器回應時間由小到大排列之五數綜合為：$\text{Min}=10, Q_1=30, \text{Median}=45, Q_3=60, \text{Max}=120$。請問下列何者屬於離群值 (Outlier)？  
> (A) 20 (B) 75 (C) 100 (D) 110
* **解析**：
  1. 計算四分位距：$IQR = Q_3 - Q_1 = 60 - 30 = 30$。
  2. 計算離群值上限：$Q_3 + 1.5 \times IQR = 60 + 1.5 \times 30 = 60 + 45 = 105$。
  3. 計算離群值下限：$Q_1 - 1.5 \times IQR = 30 - 45 = -15$。
  4. 正常範圍為 $[-15, 105]$。數值超過 105 者即為極端離群值，故 110 (D) 與 120 為離群值。

## 💡 考前 10 句精華速記 (L221)

1. **右偏（正偏）大小順序**：$\text{Mean} > \text{Median} > \text{Mode}$；平均數受大值拉動。
2. **左偏（負偏）大小順序**：$\text{Mode} > \text{Median} > \text{Mean}$；平均數受小值拉動。
3. **極端值穩健指標**：面對嚴重偏態或離群值，集中趨勢看**中位數**，離散趨勢看**四分位距 (IQR)**。
4. **經驗法則三數字**：$\pm 1\sigma \approx 68\%$、$\pm 2\sigma \approx 95\%$、$\pm 3\sigma \approx 99.7\%$（僅限常態分佈）。
5. **柴比雪夫不等式**：任意分佈下，$\pm 2\sigma$ 範圍內至少涵蓋 **75%** 的資料。
6. **卜瓦松分佈特性**：描述單位時間內隨機事件發生次數，其**平均值等於變異數** ($\mu = \sigma^2 = \lambda$)。
7. **型 I 錯誤 ($\alpha$)**：$H_0$ 為真卻被誤判拒絕（偽陽性、誤殺好人）。
8. **型 II 錯誤 ($\beta$)**：$H_0$ 為假卻未能拒絕（偽陰性、縱放壞人）。
9. **$p$ 值決策心訣**：$p < \alpha$ 拒絕 $H_0$（顯著差異）；$p \ge \alpha$ 不拒絕 $H_0$。
10. **檢定選型原則**：三組以上平均數比較用 **ANOVA**；類別與類別關聯性檢驗用 **卡方檢定 ($\chi^2$)**。
