## 📌 L22101 軟板FPC特殊材料與構造

### 1. 軟性電路板 (Flexible Printed Circuit, FPC) 特殊材料構造

軟板具備輕薄、可自由彎折立體配線、耐震動之特性，廣泛應用於智慧型手機鏡頭模組、折疊螢幕、穿戴設備與車用電池管理系統 (BMS)。其材料堆疊架構如下：

```
+-------------------------------------------------------+
|  覆蓋膜基材 (PI Film, 12.5um / 25um)                  |  <- 表面絕緣防護保護層 (Coverlay)
+-------------------------------------------------------+
|  耐熱接著膠層 (Epoxy / Acrylic Adhesive, 15um / 25um)  |  <- 接著膠 (無膠基材則無此層)
+-------------------------------------------------------+
|  導電銅箔層 (RA 壓延銅箔, 12um / 18um / 35um)         |  <- 訊號導電層
+-------------------------------------------------------+
|  核心介電基膜 (Polyimide PI Film, 12.5um / 25um)      |  <- 核心絕緣絕緣基底 (Base Film)
+-------------------------------------------------------+
|  補強板 (Stiffener, SUS不鏽鋼片 / FR-4 / 厚PI)         |  <- 焊接端子或插槽局部機械支撐
+-------------------------------------------------------+
```

* **三大特殊材料特性**：
  1. **聚醯亞胺基膜 (Polyimide, PI Film)**：
     * **優勢**：耐熱性極佳（$Tg > 250^\circ\text{C}\sim 350^\circ\text{C}$）、耐彎折耐疲勞、電氣絕緣強度高。
     * **缺點**：吸濕率偏高（約 $1.5\%\sim 3.0\%$），壓合或 SMT 回焊前**必須進行高溫除濕預烤 ($120^\circ\text{C}\sim 150^\circ\text{C}$)**，否則瞬間高溫會使內部水氣汽化膨脹引發爆板分層 (Delamination)。
  2. **三層無膠基材 (2L-FCCL) vs 有膠基材 (3L-FCCL)**：
     * **三層有膠基材 (3-Layer FCCL)**：銅箔 + 接著膠 (Adhesive, 環氧或壓克力膠) + PI 膜。缺點為膠層耐熱差、熱膨脹係數大、易老化且總厚度較厚。
     * **二層無膠基材 (2-Layer FCCL)**：透過濺鍍電鍍法 (Sputtering/Plating) 或直接塗佈熱壓法 (Casting) 將銅箔與 PI 直接結合，**無中間膠層**。優點為厚度大幅縮減、耐彎折壽命提高、耐熱性超群、尺寸安定性佳，為高階 FPC 絕對主流。

### 2. 覆蓋膜 (Coverlay) vs 液態感光防焊油墨 (Flexible Solder Mask)

軟板外層保護層有別於傳統硬板，有兩種主要防護技術：

| 評估維度 | 覆蓋膜 (Coverlay, CVL) | 軟板專用液態感光防焊油墨 (Flexible LPI) |
|---|---|---|
| **材料結構形態** | 固體膜卷形態：由聚醯亞胺膜 (PI) + 塗佈熱固性接著膠組成 | 液態黏稠油墨：高撓性改性環氧/壓克力感光樹脂 |
| **加工成型方式** | **機械沖型 (Punching) 或雷射切割**預先開出焊墊孔，對位後經高溫真空快壓/熱壓貼合 | 全板網印或噴塗後，經紫外線 (UV) 光罩**曝光、顯影**開出焊墊開口 |
| **焊墊開口解析度** | **較低**；微小焊墊容易有黏膠溢膠 (Glue Bleeding) 覆蓋焊墊風險，開口間距通常距焊墊需 $> 0.2\ mm$ | **極高**；感光成像精準，開口公差小，適合高密度微間距 (Pitch $< 0.3\ mm$) SMT 焊墊 |
| **耐彎折與機械強度** | **極致優秀**；PI 膜具極佳撕裂強度與反覆動態彎曲疲勞壽命 | 較差；反覆彎折或受劇烈折疊應力時油墨易脆裂或產生微裂紋 |
| **主要應用區域** | **動態反覆彎折滑動區** (如翻蓋手機、印表機噴頭排線、鉸鏈處) | **靜態組裝折彎區**或高密度組裝元件打件區 (Component Area) |

### 3. 補強板 (Stiffener) 材質特性與接地導電膠固定

FPC 本體柔軟，在連接器插拔（如 ZIF 插座）或 SMT 零件焊接組裝時，若缺乏足夠剛性支撐，會導致焊點開裂或插拔接觸不良，因此需在特定局部背面貼合補強板：

| 補強板種類 | 材質與機械特性 | 典型應用位置 | 與軟板之結合接著方式 |
|---|---|---|---|
| **FR-4 補強板** | 玻纖環氧樹脂板 (厚度 $0.2\sim 1.5\ mm$)，具良好剛性與耐熱性 | SMT 表面零件焊接打件背面，防止焊接時板彎翹曲 | 採用熱固化壓敏膠片 (如 3M 熱熔膠膜或壓克力接著膠) 經熱壓機貼合 |
| **SUS 不鏽鋼片 / 鋁片** | 金屬片，厚度薄（$0.1\sim 0.3\ mm$）但剛性與平整度極高、耐磨抗插拔 | 金手指插拔端（如 USB、耳機插口排線端）、狹小空間超薄支撐 | 採用純膠膜熱壓，或使用**導電膠 (Conductive Adhesive) 連接至軟板接地層**提供電磁屏蔽 (EMI) 與靜電接地 |
| **聚醯亞胺 (PI) 補強板** | 厚 PI 膜（厚度 $75\sim 225\ \mu m$），柔韌適中 | 補強 ZIF 連接器插拔厚度，滿足連接器標準公差厚度 (如 $0.3\ mm$) | 採用熱壓接著膠薄膜高溫壓合一體成型 |

## 📌 L22102 軟板捲對捲RTR生產與成型

### 1. 捲對捲 (Roll-to-Roll, RTR) 連續化自動生產
* **傳統單片生產 (Sheet-to-Sheet) 痛點**：FPC 基材厚度極薄（常 $< 50\ \mu m$），單片搬運極易產生皺褶、刮傷、卡機與對位變形。
* **RTR (Roll-to-Roll) 連續生產流程**：
  * 將長達數百公尺的捲裝 FCCL 裝載於放料軸，經連續自動張力控制系統（Tension Control）牽引，依序通過曝光、顯影、蝕刻、去膜、覆蓋膜貼合甚至表面電鍍槽液，最後於收料軸捲取。
* **RTR 核心優勢與技術挑戰**：
  * **優點**：生產速度極快、產能巨大、人工作業干預少、避免人工拿取造成的折痕刮傷不良。
  * **關鍵控制要素**：**恆張力控制 (Constant Tension Control)** 與 **自動邊界循邊導正系統 (Edge Position Control, EPC)**；張力過大會使軟板永久塑性伸長導致線路間距失真，張力過小則會起皺捲曲卡死設備滾輪。

### 2. 軟板成型技術：雷射切割 vs 機械沖模

| 評估項目 | 機械沖模成型 (Punching Die / Tooling) | 雷射輪廓切割 (UV / Green Laser Cutting) |
|---|---|---|
| **加工工具** | 雕刻五金鋼模 (Hard Tooling) 或蝕刻刀模/木模 (Soft Tooling) | 高能量脈衝紫外線雷射 (UV Laser, 波長 $355\ nm$) 冷加工光束 |
| **開模費用與前置時間** | 模具費昂貴（數萬至數十萬元），開模需 $3\sim 7$ 個工作天 | **零模具費用**，直接讀取 CAD/DXF 數位圖檔即刻加工 |
| **適用生產形態** | **大批量、成熟穩定產品**之大規模量產 | **樣品打樣、研發設計變更頻繁、小批量多樣**生產 |
| **成型加工邊界品質** | 易產生機械應力衝擊，若沖頭磨損邊緣易有毛邊 (Burrs) 與擠壓微裂痕 | **無機械切削應力**，切口乾淨垂直光潔；但雷射邊緣需防止熱影響區 (HAZ) 碳化發黑 |
| **異形與極微細加工能力**| 複雜轉角、窄間距微細狹縫難以製作沖模刀具 | 可加工極度複雜之微細幾何異形輪廓與內部微小鏤空槽 |

### 3. 軟硬結合板 (Rigid-Flex PCB) 構造與介面應力釋放

軟硬結合板將硬板（Rigid PCB）的強固支撐與高密度多層互連能力，與軟板（Flex PCB）的 3D 立體自由彎折優勢完美結合，徹底消除傳統排線連接器接插件，提升抗震可靠度並大幅節省設備內部空間。

```
       [ 硬板區 Rigid Area ]           [ 軟板過渡區 Flex Area ]          [ 硬板區 Rigid Area ]
  +-------------------------------+                             +-------------------------------+
  |  外層 FR-4 + 銅線路 + 綠漆     |                             |  外層 FR-4 + 銅線路 + 綠漆     |
  +-------------------------------+                             +-------------------------------+
  |  半固化膠片 (開窗除膠 No-Flow)|                             |  半固化膠片 (開窗除膠 No-Flow)|
  +=============================================================================================+
  |====== 軟板核心層 (2L-FCCL 壓延銅 + PI 基膜) 貫穿全板延伸 ====================================|
  +=============================================================================================+
  |  半固化膠片 (開窗除膠 No-Flow)|                             |  半固化膠片 (開窗除膠 No-Flow)|
  +-------------------------------+                             +-------------------------------+
  |  外層 FR-4 + 銅線路 + 綠漆     |                             |  外層 FR-4 + 銅線路 + 綠漆     |
  +-------------------------------+                             +-------------------------------+
                                  ^                             ^
                                  | 應力集中交界面 (軟硬交界處) |
```

* **製造關鍵工藝要點**：
  1. **軟板核心貫穿全板**：內部軟板基材一體成型連續延伸貫穿整個硬板與軟板過渡區。
  2. **不流膠半固化片 (No-Flow / Low-Flow Prepreg)**：壓合時硬板區與軟板區交界處必須「開窗（Milling Window）」。若使用普通 PP，高溫高壓下融化的環氧樹脂會溢流覆蓋到軟板彎折區，導致軟板變硬失去柔韌性；因此必須嚴格使用低流膠或無流膠 PP。
  3. **軟硬交界處應力釋放設計 (Strain Relief / Bead of Silicone)**：硬板邊緣與軟板交界處是彎折時的應力集中危險點（Stress Concentration Point），常在此交界面塗佈一圈具彈性的 UV 膠或矽膠軟膠保護珠，防止銅箔在邊緣反覆折彎時疲勞斷裂。

## 📌 L22103 微切片分析Microsection實務

### 1. 微切片金相分析 (Microsection Analysis) 標準作業規範 (IPC-TM-650 2.1.1)

微切片金相顯微檢驗是評估印製電路板內部品質（鍍層厚度、孔壁空洞、分層起泡、除膠渣品質）最權威之**破壞性檢驗方法**。標準 SOP 流程包含五大步驟：

```
取樣切塊 (Sampling) 
    │ (於板邊破壞性剪切距檢驗孔至少 2~5mm 處，切忌機械應力損傷孔結構)
    ▼
鑲埋固定 (Mounting) 
    │ (使用常溫固化壓克力樹脂或環氧樹脂倒模冷鑲埋，真空抽氣排除孔內氣泡)
    ▼
研磨 (Grinding) 
    │ (以水砂紙由粗至細 180# -> 320# -> 600# -> 1000# -> 2000# 研磨至通孔中心直徑處)
    ▼
拋光 (Polishing) 
    │ (拋光布盤配合 0.3um / 0.05um 氧化鋁水懸液或金剛石拋光膏拋至鏡面無劃痕)
    ▼
微蝕與顯微鏡觀察 (Microetching & Inspection)
    │ (以氨水/雙氧水混合液或過硫酸銨輕度微蝕顯現金屬晶界，於金相顯微鏡下量測判定)
```

---

### 2. 微切片關鍵製程操作細節與判定要點

1. **鑲埋樹脂配比 (Cold Mounting Resin)**：
   * 普遍採用常溫快乾**壓克力液體樹脂與固化粉劑**依精確比例（通常約體積比 $1:1\sim 1.2:1$）調配攪拌，避免產生過高放熱峰溫（需 $< 70^\circ\text{C}$），否則會引起板材內部熱形變。
   * **真空脫泡**：鑲埋膠液倒入樣品模具後，必須放入真空脫泡箱抽真空 $1\sim 2\ \min$，將沉積在微細通孔與盲孔內部的氣泡吸出，確保樹脂能完整充填微孔提供剛性支撐，避免後續研磨時孔壁銅箔受剪切力撕裂。
2. **研磨拋光終點判定**：
   * 研磨必須嚴格停留在**通孔中心軸線直徑處（Centerline, 允許公差 $\pm 10\%$）**。若未研磨至中心孔徑，測量得到的孔壁銅厚將會虛假偏厚！
3. **金相微蝕藥水 (Microetch Solution)**：
   * 剛拋光完成的切片在光學顯微鏡下所有金屬均呈反光鏡面，難以區分化學銅、一次銅、二次鍍銅及晶粒邊界。
   * **標準微蝕劑**：通常使用濃氨水（$\text{NH}_4\text{OH}$）與雙氧水（$\text{H}_2\text{O}_2$）按特定比例配製之鹼性微蝕液，擦拭表面 $2\sim 5\ 秒$。銅晶粒邊界受微蝕氧化後，在顯微鏡下能清晰辨識基底銅、孔壁沉積層與電鍍結晶邊界。

### 3. 熱應力測試 (Thermal Stress Test) 與微切片允收判定

* **測試標準與條件 (IPC-TM-650 2.6.8)**：
  * 將未焊元件的電路板試片在 $125^\circ\text{C}$ 預烤除濕 $2\sim 4\ 小時$ 後，置於 **$288^\circ\text{C} \pm 5^\circ\text{C}$ 的熔融高溫錫爐中浮浸漂焊 10 秒鐘**（模擬波峰焊與無鉛回焊極端熱衝擊），冷卻後進行微切片觀察。
* **熱應力微切片缺陷允收判定準則**：
  * **爆板 / 分層 (Delamination / Blistering)**：內層銅箔與膠片、或膠片與基板間嚴格**不允許出現任何裂縫或氣泡分離分層**。
  * **孔壁鍍銅開裂 (PTH Barrel Cracking)**：通孔孔壁銅層承受 $Z$ 軸熱膨脹拉伸時，**絕不允許產生任何貫穿性撕裂開路**。
  * **內層銅斷裂 / 轉角開裂 (Corner Cracking)**：孔壁與內層導線轉角處不可開裂。
  * **樹脂回縮 (Resin Recession)**：微切片孔壁邊緣樹脂因高溫微量收縮所產生的微小縫隙，在 IPC-A-600 標準中**在一定範圍內可被允許 (Acceptable)**，只要孔壁鍍銅未受損且無基材分層。

> [!WARNING] ⚠ 官方教材陷阱與關鍵細節：
> 1. **樹脂回縮 (Resin Recession) $\ne$ 分層 (Delamination)**：
>    * 樹脂回縮是環氧樹脂在高溫冷卻後沿玻璃纖維束產生的局部體積微量收縮，孔壁鍍銅完好，這在 IPC 規範中是**允許的製程外觀特性**。
>    * 爆板分層（Delamination）則是樹脂與玻纖布或銅箔之間介面附著力徹底破壞形成的大面積連續空隙裂縫，在 IPC 標準中屬於**嚴重拒收（Reject）缺陷**！
> 2. **微切片未研磨至中心線之測量陷阱**：在考試量測題中，若研磨截面切在弦線而非直徑圓心處，孔壁顯微視角會產生幾何投影放大效應，導致量測出的銅厚與孔徑失真，不能做為判定合格與否的數據。

## 🎯 考前衝刺「一句話考點」

1. 軟板 PI 基膜耐高溫達 $250^\circ\text{C}$ 以上，但因吸水率偏高在壓合或焊接前必須高溫烘烤除濕。
2. 二層無膠基材 (2L-FCCL) 省去耐熱較差的中間膠層，厚度更薄、耐高溫性與反覆彎折壽命顯著優於三層有膠基材。
3. 覆蓋膜 (Coverlay) 具超群耐反覆撓曲壽命專用於彎折區；軟板防焊油墨解析度高專用於微間距 SMT 元件區。
4. 軟板打件區需貼合 FR-4 或不鏽鋼片補強板以抵抗 SMT 焊接變形；金手指插拔端背面多貼合 PI 膜達到厚度規格。
5. 捲對捲 (RTR) 連續生產大幅減少人手拿取微薄板造成的折痕刮傷，核心控制技術為恆張力與邊緣循邊對位系統。
6. 雷射切割輪廓成型具備零模具費用與無機械切削應力特點，極適合軟板打樣與高難度異形加工。
7. 軟硬結合板壓合時，軟硬交界開窗處必須使用不流膠半固化片（No-Flow Prepreg），防止溢膠覆蓋軟板撓折區。
8. 軟硬交界處為彎曲應力集中點，標準設計會在交界面點膠塗佈彈性矽膠（Bead of Silicone）作為應力釋放保護。
9. 微切片研磨必須嚴格研磨至通孔中心直徑軸線處，未達中心軸線量測之孔銅厚度會失真虛厚。
10. 熱應力測試條件為 $288^\circ\text{C}$ 熔融錫浮浸 10 秒；樹脂回縮在 IPC 規範下允許，但層間分層起泡一律判定拒收。
