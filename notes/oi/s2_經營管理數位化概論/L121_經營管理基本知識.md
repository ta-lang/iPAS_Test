### 2. 產業競爭分析：波特五力分析 (Porter's Five Forces)
麥可·波特提出決定產業獲利吸引力與競爭強度的五大關鍵力量：

```
                    ┌─────────────────────────┐
                    │    潛在進入者的威脅      │
                    │ (Threat of New Entrants)│
                    └────────────┬────────────┘
                                 │
                                 ▼
┌──────────────────┐  ┌──────────────────────┐  ┌──────────────────┐
│   供應商的議價能力 │─▶│   產業內現有競爭者   │◀─│   買方的議價能力  │
│  (Bargaining     │  │ (Rivalry Among       │  │  (Bargaining     │
│   Power of       │  │  Existing Competitors)│  │   Power of Buyers│
│   Suppliers)     │  └──────────────────────┘  │   )              │
└──────────────────┘             ▲              └──────────────────┘
                                 │
                    ┌────────────┴────────────┐
                    │    替代品或服務的威脅    │
                    │ (Threat of Substitutes) │
                    └─────────────────────────┘
```

1. **現有競爭者的競爭程度**：競爭對手多、產業成長緩慢、退出障礙高時，競爭最激烈。
2. **潛在進入者的威脅**：取決於「進入障礙」高低（如規模經濟、專利技術、資本規模需求）。
3. **替代品或服務的威脅**：非同業但可滿足消費者相同需求的商品（如高鐵 vs 國內航空）。
4. **買方的議價能力**：買方集中度高、採購量大、轉換成本低時，買方議價力極強。
5. **供應商的議價能力**：供應商寡占、無有效替代品、轉換供應商成本高時，供應商議價力強。

### 3. 策略分析矩陣對比：SWOT 分析 vs BCG 矩陣

#### A. SWOT 分析矩陣與策略配對

| 內部 \ 外部 | 機會 (Opportunities, O) | 威脅 (Threats, T) |
|---|---|---|
| **優勢 (Strengths, S)** | **SO 增長策略 (Maxi-Maxi)**：發揮內部優勢，全面搶佔外部機會 | **ST 多元化策略 (Maxi-Mini)**：運用內部優勢，抵禦或化解外部威脅 |
| **劣勢 (Weaknesses, W)**| **WO 轉向策略 (Mini-Maxi)**：克服內部劣勢，利用外部新興機會 | **WT 防禦策略 (Mini-Mini)**：克服內部劣勢，避開外部致命威脅（如撤退或結盟） |

#### B. BCG 波士頓矩陣 (BCG Matrix)

| 市場成長率 \ 相對市佔率 | 高相對市佔率 (High Share) | 低相對市佔率 (Low Share) |
|---|---|---|
| **高市場成長率 (High Growth)** | **明星業務 (Stars)**：現金收支大致平衡，需持續投資維持領先地位 | **問題業務 (Question Marks)**：需消耗大量現金投資，具轉為明星之潛力 |
| **低市場成長率 (Low Growth)** | **金牛業務 (Cash Cows)**：產生大量充沛自由現金流，為企業營運發動機 | **瘦狗業務 (Dogs)**：獲利極低甚至虧損，應評估剝離、縮減或停損清算 |

### 4. 錢德勒組織架構名言 (Alfred Chandler)
* **核心理論**：「**結構跟隨策略 (Structure follows Strategy)**」。
* **內涵**：企業組織的架構設計必須隨企業營運策略與業務擴張模式之改變而調整。若策略轉型而組織結構僵化未變，將導致協同失效與重大經營瓶頸。

### 2. 專案管理方法論：甘特圖 (Gantt Chart) vs 計畫評核術 (PERT / CPM)

| 比較項目 | 甘特圖 (Gantt Chart) | 計畫評核術 (PERT) / 關鍵路徑法 (CPM) |
|---|---|---|
| **發明背景** | Henry Gantt 提出，以橫條圖視覺化表示 | 美國海軍北極星飛彈專案提出，以網路圖 (Network Diagram) 表示 |
| **核心優勢** | 時程排程直觀、任務起始日與進度百分比清晰 | 能精確表達作業前後邏輯依賴性 (Precedence)，並找出關鍵路徑 |
| **時間估算特性**| 確定性單一時間長度表示 | **三時估計法**，具備機率與不確定性模型 |
| **關鍵路徑支援**| 無法直接運算與識別浮時 (Float) | 嚴格運算最早/最晚起訖時間，精確標示**浮時為零**的關鍵路徑 |

### 3. PERT 三時估計法公式與關鍵路徑計算題實戰
PERT 假設任務時間符合貝他分佈 (Beta Distribution)，採用三種時間估計值：
1. **樂觀時間 ($O$, Optimistic Time)**：一切極度順利下的最短耗時。
2. **最可能時間 ($M$, Most Likely Time)**：正常情況下最常見的耗時。
3. **悲觀時間 ($P$, Pessimistic Time)**：各種不利因素阻礙下的最長耗時。

* **期望完成時間 ($T_e$, Expected Duration)**：
  $$T_e = \frac{O + 4M + P}{6}$$
* **作業時間變異數 ($\sigma^2$)**：
  $$\sigma^2 = \left( \frac{P - O}{6} \right)^2$$
* **關鍵路徑 (Critical Path)**：
  * 專案網路圖中**總耗時最長的一條路徑**。
  * 關鍵路徑上的作業之**總浮時 (Total Float) 為 0**。
  * 關鍵路徑上的任何延誤，將等量導致整個專案的最終完工期延誤。

> **【實戰計算範例】**：  
> 某數位轉型專案包含 A、B、C 三項作業，其先後順序為 A $\rightarrow$ B $\rightarrow$ C。各項作業的三時估計如下表所示：  
> - 作業 A：$O = 2$ 天，$M = 5$ 天，$P = 8$ 天。  
> - 作業 B：$O = 3$ 天，$M = 6$ 天，$P = 15$ 天。  
> - 作業 C：$O = 4$ 天，$M = 7$ 天，$P = 10$ 天。  
> 試計算專案的預期關鍵路徑總完工時間 $T_e$ 為多少天？  
> **【計算步驟】**：  
> 1. 計算作業 A 期望時間：  
>    $$T_e(A) = \frac{2 + 4 \times 5 + 8}{6} = \frac{2 + 20 + 8}{6} = \frac{30}{6} = 5 \text{ 天}$$  
> 2. 計算作業 B 期望時間：  
>    $$T_e(B) = \frac{3 + 4 \times 6 + 15}{6} = \frac{3 + 24 + 15}{6} = \frac{42}{6} = 7 \text{ 天}$$  
> 3. 計算作業 C 期望時間：  
>    $$T_e(C) = \frac{4 + 4 \times 7 + 10}{6} = \frac{4 + 28 + 10}{6} = \frac{42}{6} = 7 \text{ 天}$$  
> 4. 關鍵路徑總預期完工時間：  
>    $$T_e(\text{總工期}) = T_e(A) + T_e(B) + T_e(C) = 5 + 7 + 7 = 19 \text{ 天}$$

### 🎯 考前衝刺「一句話考點」
1. **PEST 分析** 專注於總體外部環境：政治 (P)、經濟 (E)、社會 (S)、科技 (T)。
2. **波特五力分析** 探討產業競爭環境：現有競爭者、潛在進入者、替代品威脅、買方議價力、供應商議價力。
3. **SWOT 分析** 中，內部優勢搭配外部威脅所擬定之策略為 **ST 多元化策略**。
4. **BCG 矩陣** 中，處於低市場成長率但高相對市佔率的事業單位稱為**金牛 (Cash Cows)**。
5. 錢德勒 (Alfred Chandler) 的策略名言為「**結構跟隨策略 (Structure follows Strategy)**」。
6. 現代行銷理論從企業視角的 **4P (Product, Price, Place, Promotion)** 演進為顧客導向的 **4C (Customer solution, Cost, Convenience, Communication)**。
7. **甘特圖 (Gantt Chart)** 適合呈現直觀進度與時程長度；**PERT/CPM 網路圖** 適合分析複雜前後邏輯關係與計算關鍵路徑。
8. PERT 三時估計法期望完成時間公式為：$T_e = \frac{O + 4M + P}{6}$。
9. 專案網路圖中，**關鍵路徑 (Critical Path)** 是總耗時最長的路徑，其作業浮時 (Float) 為 0。
10. 壓縮專案工期時，僅有對**關鍵路徑上的作業進行趕工 (Crashing)** 才能有效縮短專案總時程。
