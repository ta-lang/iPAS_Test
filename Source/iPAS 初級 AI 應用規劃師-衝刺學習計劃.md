## 📖 核心學習資料與知識點精華

🎯 模組一：L11 人工智慧基礎概論

1. 人工智慧概念與治理（L111）

- **AI 的定義與分類**：
    
    - **弱人工智慧（ANI）**：專注於單一特定任務（目前絕大多數的 AI 應用）。
        
    - **強人工智慧（AGI）**：具備與人類相當的廣泛認知與學習能力。
        
- **必考治理框架與法規** ：
    
    - **國際趨勢**：歐盟《人工智慧法案（AI Act）》（採取風險基礎分類法，分為不可接受、高、中、低風險） 。
        
    - **台灣核心規範**：數位發展部《公部門人工智慧應用參考手冊》、數位部《AI 產品與系統評測》、金管會《金融業運用人工智慧（AI）指引》 。主要強調**透明性、可解釋性、資料隱私與反歧視**。
        

2. 資料處理與分析概念（L112）

- **資料型態**：數值型（結構化）、文字/圖像/語音（非結構化） 。
    
- **資料整理標準流程（CRISP - DM / Pipeline）** ：
    
    1. **資料收集** $\rightarrow$ 2. **資料清理**（處理缺失值、異常值、去噪） $\rightarrow$ 3. **特徵工程**（特徵選取、資料標準化 / 歸一化，提升模型訓練效率） $\rightarrow$ 4. **分析與呈現** 。
        
- **資料隱私**：去識別化（匿名化、去標識化）、符合 GDPR 或國內個資法規範 。
    

3. 機器學習概念（L113）

- **模型訓練與泛化機制**：理解過擬合（Overfitting，在訓練集表現好但測試集差）與欠擬合（Underfitting）的成因與調整方法。
    
- **四大機器學習模型分類** ：
    
    - **監督式學習**：資料「有標籤（Label）」，如分類（Classification）、迴歸（Regression） 。
        
    - **非監督式學習**：資料「無標籤」，如分群（Clustering, K-Means）、降維 。
        
    - **半監督式學習**：少量標籤資料搭配大量無標籤資料 。
        
    - **強化式學習**：透過環境給予的「獎勵與懲罰機制」進行學習（如 AlphaGo） 。
        
    - **多模態學習**：同時處理並理解多種不同類型媒介（如文字＋圖像＋聲音）的模型 。
        

4. 鑑別式 AI 與 生成式 AI 概念（L114）

- **鑑別式 AI（Discriminative AI）**：預現有資料的標籤或分類（例如：判斷這張照片是不是貓、垃圾信件過濾） 。
    
- **生成式 AI（Generative AI）**：學習資料的潛在機率分佈，進而「創造新資料」（例如：寫文章、畫圖） 。
    
- **效能管理與測試**：模型部署後的漂移（Drift）監控、精準度（Precision）、召回率（Recall）等指標基礎認知 。
    

🎯 模組二：L12 生成式 AI 應用與規劃

1. No code / Low code 概念（L121）

- **基本概念**：利用視覺化拖拉界面或減量程式碼，降低非技術人員開發 AI 應用的門檻 。
    
- **優勢與限制** ：
    
    - _優勢_：快速驗證（MVP）、降低開發成本、提升業務部門（LOB）敏捷度 。
        
    - _限制_：客製化彈性低、平台鎖定（Vendor Lock-in）、資安與影子 IT（Shadow IT）風險 。
        

2. 生成式 AI 應用領域與工具使用（L122）

- **核心工具清單與場域** ：
    
    - **文本 / 通用**：ChatGPT、Gemini 。
        
    - **圖像生成**：Midjourney 。
        
    - **開發輔助**：GitHub Copilot、Cursor、VS Code for Copilot 。
        
    - **企業自動化 / Agent**：Copilot Studio 。
        
- **高效運用技術** ：
    
    - **提示工程（Prompt Engineering）**：掌握提示詞框架（如特徵角色、上下文、任務目標、輸出格式限制） 。
        
    - **RAG（檢索增強生成）**：企業解決大模型「幻覺（Hallucination）」的核心技術。透過外掛知識庫（向量資料庫），讓 AI 在回答前先檢索正確資訊，確保回覆的精準度與時效性 。
        

3. 生成式 AI 導入評估規劃（L123）

- **評估指標**：技術可行性、ROI 成本效益分析、適用解決方案（商業 API vs. 開源微調） 。
    
- **官方核心指引**：務必閱讀經濟部產業發展署發布的《AI 導入指引》（包含目標設置、資源分配與導入策略步驟） 。
    
- **風險管理** ：
    
    - **倫理風險**：偏見輸出、著作權爭議。
        
    - **資安隱私**：機密資料外洩（例如員工將未公開財報餵給公開版 ChatGPT） 。
        

## 💡 備考實戰建議

1. **法規題是基本分**：數發部的《公部門人工智慧應用參考手冊》與產發署的《AI 導入指引》，考前務必上網下載並瀏覽其「核心大綱」與「原則」，這類題目多為觀念題，極好拿分 。
    
2. **釐清專門術語**：考題常會出現混淆選項（例如：將 RAG 的定義與微調 Fine-tuning 搞混，或將監督式與非監督式的應用場景錯置），務必確保自己能用一句話清楚解釋兩者的差別 。
    
3. **多關注工具整合**：由於初級強調「應用規劃」，了解各個 Low-code 工具或 OpenAI API 的基本呼叫與整合邏輯（不需要考寫程式，但要懂工作流），能幫你在 L12 模組拿到高分 。
