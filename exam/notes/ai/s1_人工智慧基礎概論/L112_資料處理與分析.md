## 📌 L11201 資料基本概念與來源

### 1. 三大資料結構型態比較

在機器學習與資料前處理中，資料依其格式嚴謹度分為三大形態：

| 資料類型 | 定義與特徵 | 典型格式範例 | 適用預處理方式 |
|---|---|---|---|
| **結構化資料**<br>*(Structured Data)* | • 具備固定 Schema、清楚的行列二維表格關係<br>• 欄位型別（數值、日期、布林）定義嚴謹 | 關聯式資料庫 (RDBMS/SQL)、Excel 試算表、CSV（欄位固定者） | 缺失值插補、標準化 ($Z$-Score)、One-Hot 編碼 |
| **半結構化資料**<br>*(Semi-structured Data)* | • 不具備嚴格的資料庫表格結構<br>• 具有自我描述性標籤 (Self-describing tags) 或巢狀鍵值對 | **JSON**、**XML**、HTML、NoSQL 文檔資料庫 | 剖析 (Parsing) 展平 (Flatten)、抽取特定鍵值轉換成數值矩陣 |
| **非結構化資料**<br>*(Unstructured Data)* | • 沒有預定義的資料模型或欄位結構<br>• 在企業與網際網路中佔比超過 80% | 影像 (JPG/PNG)、語音 (WAV/MP3)、視訊 (MP4)、自由格式文字 (PDF、維修工單手寫記錄) | 電腦視覺特徵提取 (CNN/ViT)、NLP 斷詞與詞嵌入 (Tokenization/Embedding) |

---

### 2. 資料來源分類與特徵
1. **第一手資料 (Primary Data)**：由研究者或企業直接為特定目的所收集之資料（如：問卷調查、產線 IoT 感測器即時串流數據、自營電商會員點擊日誌）。
2. **第二手資料 (Secondary Data)**：非為當前特定專案而收集，但可再利用之資料（如：政府開放資料 Open Data、學術公開資料集、產業研究報告）。

## 📌 L11202 資料整理與分析流程

### 1. 集中趨勢測量數 (Measures of Central Tendency)

* **算術平均數 (Arithmetic Mean, $\mu$ 或 $\bar{X}$)**：
  $$\bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i$$
  * *特點*：代表資料的「物理重心」；**極易受極端值（離群值）拉動牽引**。
* **中位數 (Median, $M_d$)**：
  * 將所有數值由小到大排序後，位於正中間位置的數值。
  * *特點*：**不受極端值影響**，在偏態分佈（如國民薪資、房價）中最能代表一般大眾水準。
* **眾數 (Mode, $M_o$)**：
  * 資料集中出現頻率最高的值。
  * *特點*：**唯一可用於類別型/名目型資料 (Categorical/Nominal Data)** 的集中趨勢指標；可能有多個（雙峰）或不存在。

#### 📊 偏態 (Skewness) 與平均數、中位數、眾數之大小關係

```
   常態分佈 (無偏態)           右偏分佈 (正偏態)            左偏分佈 (負偏態)
      對稱鐘形                長尾朝向右方 (高值側)        長尾朝向左方 (低值側)
      
       /\                         /\                            /\
      /  \                       /  \                          /  \
     /    \                     /    \                        /    \
    /      \                   /      \                      /      \
   /________\                 /________\______              ______/________\
 Mean = Median = Mode        Mode < Median < Mean          Mean < Median < Mode
```

* **常態分佈 (Symmetric)**：$\text{Mean} = \text{Median} = \text{Mode}$
* **正偏態 / 右偏分佈 (Right-skewed)**：極大值將平均數向右拉扯 $\Rightarrow \mathbf{\text{Mode} < \text{Median} < \text{Mean}}$ （如：所得分佈、房價）。
* **負偏態 / 左偏分佈 (Left-skewed)**：極小值將平均數向左拉扯 $\Rightarrow \mathbf{\text{Mean} < \text{Median} < \text{Mode}}$ （如：容易的考試成績）。

### 2. 離散程度測量數 (Measures of Dispersion)

> [!WARNING]
> ### ⚠ 官方教材勘誤重點 (一)
> **平均差（Mean Deviation / Mean Absolute Deviation）**：
> * **原教材誤植**：「每一個觀察值與平均數之間的差距，其數值越大表示分散程度越高。」
> * **官方勘誤更正**：「**是所有觀察值與平均數之間絕對差值的平均**，其數值越大，表示資料的分散程度越高。」
> * **數學定義式**：
>   $$\text{MD} = \frac{1}{n}\sum_{i=1}^{n} |X_i - \bar{X}|$$

* **全距 (Range, $R$)**：
  $$R = X_{\max} - X_{\min}$$
  * *缺點*：僅考慮最大與最小兩端點，極端敏感於異常值，無法反映中間分佈。
* **四分位距 (Interquartile Range, IQR)**：
  $$\text{IQR} = Q_3 - Q_1$$
  * *特點*：衡量中間 50% 資料的分散範圍，**抗極端值干擾（具穩健性 Robustness）**。
* **標準差 (Standard Deviation, $\sigma$ 或 $s$)**：
  $$s = \sqrt{\frac{1}{n-1}\sum_{i=1}^{n} (X_i - \bar{X})^2}$$
  * *特點*：具備原量測單位，受極端值影響，廣泛應用於常態假設與品質管制。

### 3. 四分位距與離群值偵測計算範例 (Boxplot Worked Example)

> **【實戰計算範例】**：
> 某設備連續 9 次運轉測試所得數據如下（已排序）：
> $$[10, 12, 15, 18, 20, 22, 25, 30, 60]$$
> 請計算 $Q_1, Q_2, Q_3, \text{IQR}$ 並判斷 $60$ 是否為離群值？
> 
> **【計算步驟】**：
> 1. 樣本數 $n = 9$：
>    * 中位數 $Q_2 = 20$（第 5 個數值）。
>    * 下半部數組 $[10, 12, 15, 18]$，其第 1 四分位數 $Q_1 = \frac{12 + 15}{2} = 13.5$。
>    * 上半部數組 $[22, 25, 30, 60]$，其第 3 四分位數 $Q_3 = \frac{25 + 30}{2} = 27.5$。
> 2. 計算四分位距：
>    $$\text{IQR} = Q_3 - Q_1 = 27.5 - 13.5 = 14$$
> 3. 計算盒鬚圖內籬笆 (Inner Fences) 上限門檻：
>    $$\text{Upper Threshold} = Q_3 + 1.5 \times \text{IQR} = 27.5 + 1.5 \times 14 = 27.5 + 21 = 48.5$$
> 4. 判斷結論：
>    因為數值 $60 > 48.5$，故數值 $60$ 判定為**統計離群值 (Outlier)**。

### 4. 資料清理與特徵前處理技術

| 前處理環節 | 常見問題 | 推薦處理策略與考量 |
|---|---|---|
| **遺缺值處理**<br>*(Missing Values)* | 感測器掉線、用戶未填答 | • **時序數據 (Time-series)**：優先採用**前後相鄰時間點線性插補 (Linear Interpolation)**，不可直接補 0 或總平均值，以避免破壞連續性。<br>• **數值特徵**：常態分佈補平均數，偏態分佈補中位數。<br>• **遺失比例過高 (> 60%)**：評估直接剔除特徵欄位。 |
| **類別編碼**<br>*(Categorical Encoding)* | 演算法僅能接收純數值輸入 | • **無序名目變數 (Nominal)**（如性別、居住城市）：採用 **One-Hot Encoding**，不可直接使用 Label Encoding（會讓線性模型誤判 3 > 2 > 1）。<br>• **有序變數 (Ordinal)**（如教育程度、軍階）：採用 **Ordinal Encoding** 保留階層大小順序。 |
| **特徵縮放**<br>*(Feature Scaling)* | 特徵單位尺度差異巨大 | • **$Z$-Score 標準化**：$Z = \frac{X - \mu}{\sigma}$，適用於 KNN、SVM、神經網路。<br>• **Min-Max 常規化**：$X' = \frac{X - X_{\min}}{X_{\max} - X_{\min}} \in [0, 1]$。<br>• **決策樹 (Decision Tree) 與隨機森林對特徵縮放最不敏感**，無需縮放。 |

## 📌 L11203 資料隱私與安全

### 1. 抽樣變異與假設檢定勘誤精要

> [!WARNING]
> ### ⚠ 官方教材勘誤重點 (二)
> **抽樣變異（Sampling Variation）的嚴謹定義**：
> * **官方勘誤更正**：「在進行統計分析時，從母體中抽取樣本所計算出的統計量（如樣本平均數、樣本標準差），往往**因樣本的隨機性而與對應的母體參數有所差異**。這種**因抽樣而產生的統計量變動現象，稱為抽樣變異 (Sampling Variation)**。」

> [!WARNING]
> ### ⚠ 官方教材勘誤重點 (三)
> **型一錯誤 ($\alpha$) 與型二錯誤 ($\beta$) 混淆矩陣勘誤**：
> 
> | 檢定決策 \ 實際真實情況 | $H_0$ 為真 (無效/健康) | $H_0$ 為假 (有效/生病) |
> |---|---|---|
> | **接受 $H_0$** (判為無效) | 決策正確 ($1 - \alpha$) | **型二錯誤 ($\beta$, Type II Error)** *(存偽)* |
> | **拒絕 $H_0$** (判為有效) | **型一錯誤 ($\alpha$, Type I Error)** *(棄真)* | 決策正確 / 檢定力 ($1 - \beta$, Power) |
> 
> * **教材更正重點**：拒絕 $H_0$ 且 $H_0$ 為真時為 **Type I 錯誤 ($\alpha$)**（原教材誤植為 Type II 錯誤）。
> * **$p$ 值與顯著水準詮釋勘誤題**：若顯著水準 $\alpha = 0.05$，$p\text{-value} = 0.03 < 0.05$：
>   * 正確敘述：「**我們在 95% 的信心水準下拒絕虛無假設 ($H_0$)**。」
>   * 錯誤敘述：「我們犯型一錯誤的機率為 5%」（$\alpha = 0.05$ 是容許上限，並非實際犯錯機率）。

### 2. 個資去識別化 (De-identification) 與安全規範

* **遮蔽 (Masking)**：將身分證字號或姓名部分字元置換為星號（如：`A12****789`）。
* **雜湊加密 (Hashing)**：透過單向不可逆雜湊函式（如 SHA-256）進行加鹽（Salt）轉換。
* **$k$-匿名性 ($k$-Anonymity)**：在同一個資料集中，使任何一個人的準識別碼組合（如：年齡、性別、郵遞區號）**至少與其他 $k-1$ 個人的特徵完全相同**，讓外部攻擊者無法鎖定特定個體（機率不超過 $1/k$）。
* **實務合規陷阱**：
  * 若企業將個資經過 MD5 雜湊，但**內部仍妥善保留著明文與雜湊對照映射表**，在法律與法遵審計上**仍視為具備可識別性之個人資料**，不屬於完全去識別化資料。

### 🎯 考前衝刺「一句話考點」
1. **結構化資料**具備固定二維行列（SQL/Excel），**非結構化資料**（圖片、音訊、自由文本）在真實世界中佔比超過 80%。
2. **算術平均數**極易受極端值拉動，**中位數**具備穩健性，在偏態分佈（薪資、房價）中最具代表性。
3. **正偏態（右偏）**分佈中，數值大小關係為：$\mathbf{\text{Mode} < \text{Median} < \text{Mean}}$。
4. **四分位距 (IQR)** 計算為 $Q_3 - Q_1$，盒鬚圖的外線門檻為 $Q_3 + 1.5 \times \text{IQR}$。
5. 【勘誤】**平均差 (MD)** 是「所有觀察值與平均數之間**絕對差值**的平均」。
6. 【勘誤】因隨機抽樣導致樣本統計量與母體參數之間的自然變動，稱為**抽樣變異 (Sampling Variation)**。
7. 【勘誤】虛無假設 $H_0$ 為真卻被檢定拒絕，所犯的錯誤稱為**型一錯誤 (Type-I Error, $\alpha$)**。
8. 顯著水準 $\alpha = 0.05$ 代表「**容許犯型一錯誤的最大機率上限為 5%**」，並非實際犯錯機率。
9. 時序資料若有遺缺值，應使用**相鄰時間點線性插補 (Linear Interpolation)**，不可填補 0 或全體平均值。
10. **決策樹演算法**對特徵量綱尺度的差異最不敏感，訓練前無需強制進行標準化。
