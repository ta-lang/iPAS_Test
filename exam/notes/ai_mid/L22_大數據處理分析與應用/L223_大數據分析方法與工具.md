## 📌 L22301 統計學在大數據中的應用

### 1. 資料轉換與分佈調整
* **對數轉換 (Log Transformation)**：
  * 對右偏（長尾）分佈資料取 $\log(X)$，壓縮極大值尺度，使分佈更接近常態分佈，穩定變異數。
* **Box-Cox 轉換**：
  * 參數化冪次轉換，透過最大似然估計尋求最佳參數 $\lambda$，將非正態連續資料轉換為近似常態分佈。
* **特徵縮放 (Feature Scaling)**：
  * **Min-Max 歸一化 (Normalization)**：
    $$X' = \frac{X - X_{\min}}{X_{\max} - X_{\min}} \in [0, 1]$$
    * 易受極端離群值影響；若有新資料超出原始邊界會產生截斷問題。
  * **Z-score 標準化 (Standardization)**：
    $$Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$$
    * 將特徵轉換為均值為 0、標準差為 1 的分佈，對離群值較具穩健性。

### 2. 相關性分析與特徵降維
* **皮爾森相關係數 (Pearson Correlation, $r$)**：
  * 衡量兩連續變數間之**線性關聯強度**，數值介於 $[-1, +1]$。
  * $r = 1$：完全正線性相關；$r = -1$：完全負線性相關；$r = 0$：無線性相關（但可能存在非線性關係）。
* **主成分分析 (PCA, Principal Component Analysis)** [🎯 常考]：
  * **無監督學習 (Unsupervised)** 降維技術。
  * 尋找使投影後**資料變異數最大化 (Maximize Variance)** 的正交軸（主成分）。
  * 核心價值：消除多重共線性 (Multicollinearity)、降低特徵維度以緩解維度災難、節省運算資源。

## 📌 L22302 常見的大數據分析方法與核心演算法

### 1. 關聯規則挖掘 (Association Rules) 與三大指標 [🎯 計算必考]

假設交易資料集中，買了商品 $A$ 也買商品 $B$ 的規則記為 $A \rightarrow B$：

| 指標名稱 | 統計意涵與公式 | 解讀門檻與判斷準則 |
|---|---|---|
| **支援度 (Support)** | $A$ 與 $B$ 同時出現在同一筆交易中的機率：<br/>$$\text{Support}(A \rightarrow B) = P(A \cap B) = \frac{\text{同時含 } A, B \text{ 的交易數}}{\text{總交易數}}$$ | 衡量規則的「普遍性/重要性」。若支援度太低代表為罕見偶然事件。 |
| **信賴度 / 置信度 (Confidence)** | 在購買 $A$ 的前提條件下，同時購買 $B$ 的條件機率：<br/>$$\text{Confidence}(A \rightarrow B) = P(B \mid A) = \frac{P(A \cap B)}{P(A)}$$ | 衡量規則的「可靠性/準確度」。 |
| **提升度 (Lift)** | 購買 $A$ 對購買 $B$ 的促進倍數：<br/>$$\text{Lift}(A \rightarrow B) = \frac{\text{Confidence}(A \rightarrow B)}{P(B)} = \frac{P(A \cap B)}{P(A) \times P(B)}$$ | 衡量關聯的「實質有效性」：<br/>• **$\text{Lift} > 1$**：正向促進關聯（推薦有效）。<br/>• **$\text{Lift} = 1$**：兩者獨立無關。<br/>• **$\text{Lift} < 1$**：負向排斥關聯（互斥）。 |

### 2. 不平衡資料集 (Imbalanced Data) 處理策略 [🎯 常考]
* **欠採樣 (Undersampling)**：隨機剔除多數類樣本。缺點：可能遺失多數類的關鍵代表性資訊。
* **過採樣 (Oversampling)**：隨機複製少數類樣本。缺點：容易導致模型對少數類產生**過擬合**。
* **SMOTE (Synthetic Minority Over-sampling Technique)** [🎯 必考]：
  * **運作機制**：在特徵空間中，對少數類樣本利用其 $K$ 近鄰進行線性插值，**合成生成全新且具多樣性的少數類虛擬樣本**，避免單純複製造成的過擬合。
* **代價敏感學習 (Cost-Sensitive Learning)**：在損失函數中賦予少數類更高的誤判懲罰權重。

### 3. [⚠ 勘誤] 分類模型評估指標與混淆矩陣 (Confusion Matrix) [🎯 計算必考]

| 真實狀況 \ 模型預測 | 預測為正類 (Positive) | 預測為負類 (Negative) |
|---|---|---|
| **實際為正類 (Actual Positive)** | **TP (True Positive, 真陽性)** | **FN (False Negative, 偽陰性/漏報)** |
| **實際為負類 (Actual Negative)** | **FP (False Positive, 偽陽性/誤報)** | **TN (True Negative, 真陰性)** |

#### 四大核心評估指標公式：
1. **準確率 (Accuracy)**：
   $$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$
   * *限制*：在高度不平衡資料下（如信用卡詐欺僅佔 0.1%），無腦全猜負類即可達 99.9% 準確率，指標失去鑑別度。
2. **精確率 (Precision, 查準率)**：
   $$\text{Precision} = \frac{TP}{TP + FP}$$
   * 意涵：預測為正類的所有案例中，實際上真正為正類的比例（防誤報）。
3. **[⚠ 勘誤] 召回率 (Recall, 查全率 / 敏感度 Sensitivity)**：
   $$\text{Recall} = \frac{TP}{TP + FN}$$
   * *(勘誤重點：指引 P.5-21 更正分母嚴格為 $TP + FN$，原誤植為 $TP + FP$)*。
   * 意涵：所有實際為正類的案例中，成功被模型揪出來的比例（防漏報）。
4. **F1-分數 (F1-Score)**：
   $$F_1 = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2TP}{2TP + FP + FN}$$
   * 意涵：Precision 與 Recall 之調和平均數 (Harmonic Mean)，專門評估不平衡資料集之綜合表現。

#### ROC 曲線與 AUC 指標：
* **ROC 曲線 (Receiver Operating Characteristic)**：
  * 橫軸為 **FPR (偽陽性率)**：$FPR = \frac{FP}{FP + TN}$ (負類被誤判為正類的比例)。
  * 縱軸為 **TPR (真陽性率 / Recall)**：$TPR = \frac{TP}{TP + FN}$。
* **AUC (Area Under Curve)**：ROC 曲線下方的面積，取值於 $[0.5, 1.0]$。$\text{AUC} = 0.5$ 代表隨機瞎猜；$\text{AUC} = 1.0$ 代表完美分類器。

## 📌 L22303 數據可視化工具與選型

| 圖表類型 | 核心表達目的 | 經典適用場景 |

| **散佈圖 (Scatter Plot)** | 呈現兩連續變數之間的相關性與分佈趨勢 | 身高 vs 體重相關性、PCA 降維視覺化 |

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

# 載入資料與分割

model.fit(X_train, y_train)

## 🧮 歷屆核心計算題範例精解

### 範例 1：關聯規則三大指標計算
> **題目**：某超商共記錄 1000 筆購物交易。其中有 200 筆購買了「咖啡」，300 筆購買了「麵包」，有 100 筆同時購買了「咖啡」與「麵包」。請問規則 $\text{咖啡} \rightarrow \text{麵包}$ 的支援度、信賴度與提升度分別為何？
* **解析**：
  1. $\text{Support}(\text{咖啡} \rightarrow \text{麵包}) = \frac{100}{1000} = 0.10 \; (10\%)$
  2. $\text{Confidence}(\text{咖啡} \rightarrow \text{麵包}) = \frac{100}{200} = 0.50 \; (50\%)$
  3. $P(\text{麵包}) = \frac{300}{1000} = 0.30$
  4. $\text{Lift}(\text{咖啡} \rightarrow \text{麵包}) = \frac{\text{Confidence}}{P(\text{麵包})} = \frac{0.50}{0.30} \approx 1.67$
  5. **結論**：提升度 $1.67 > 1$，表示購買咖啡對購買麵包具有顯著的正向促進效應！

### 範例 2：混淆矩陣與各指標計算
> **題目**：某醫療 AI 篩檢系統對 100 位受檢者進行疾病預測，實際與預測混淆矩陣如下：  
> • $TP = 20$（實際有病，預測有病）  
> • $FN = 5$（實際有病，預測沒病）  
> • $FP = 10$（實際沒病，預測有病）  
> • $TN = 65$（實際沒病，預測沒病）  
> 請計算該系統的準確率、精確率、召回率與 F1-score。
* **解析**：
  1. $\text{Accuracy} = \frac{TP + TN}{100} = \frac{20 + 65}{100} = 0.85 \; (85\%)$
  2. $\text{Precision} = \frac{TP}{TP + FP} = \frac{20}{20 + 10} = \frac{20}{30} \approx 0.667 \; (66.7\%)$
  3. $\text{Recall} = \frac{TP}{TP + FN} = \frac{20}{20 + 5} = \frac{20}{25} = 0.80 \; (80\%)$
  4. $F_1 = \frac{2 \times 0.667 \times 0.80}{0.667 + 0.80} = \frac{1.067}{1.467} \approx 0.727$

## 💡 考前 10 句精華速記 (L223)

1. **對數轉換 (Log)**：專門用來處理右偏長尾資料，使其更貼近常態分佈。
2. **PCA 主成分分析**：無監督降維演算法，核心目標是尋求**最大化變異數**的正交方向。
3. **提升度 (Lift) 意義**：$\text{Lift} > 1$ 促銷推薦有效；$\text{Lift} = 1$ 兩商品獨立；$\text{Lift} < 1$ 負相關互斥。
4. **SMOTE 核心技術**：利用少數類樣本的 $K$ 近鄰進行線性插值生成**新虛擬樣本**，避免單純過採樣的過擬合。
5. **不平衡資料看 Accuracy**：高度不平衡下 Accuracy 失真，應以 **F1-Score 或 PR-AUC** 作為主要指標。
6. **Precision vs. Recall 取捨**：垃圾郵件過濾重 Precision（防誤判正信）；癌症篩檢重 **Recall**（寧可抓錯不可漏網）。
7. **Recall 公式 [⚠ 勘誤]**：$\text{Recall} = \frac{TP}{TP + FN}$，分母是所有實際為正的樣本總和。
8. **ROC 曲線之座標軸**：橫軸為偽陽性率 ($FPR = 1 - \text{Specificity}$)，縱軸為真陽性率 ($TPR = \text{Recall}$)。
9. **相關係數矩陣可視化**：呈現多特徵間成對相關程度，首選 **熱力圖 (Heatmap)**。
10. **趨勢變化圖表首選**：觀察隨時間推進的趨勢變化，標準選擇為 **折線圖 (Line Chart)**。
