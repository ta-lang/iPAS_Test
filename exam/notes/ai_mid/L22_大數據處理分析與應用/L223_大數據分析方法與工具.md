## 📌 L22301 統計學在大數據中的應用

### 1. 資料轉換、特徵縮放與分位數技術
* **對數轉換 (Log Transformation)**：
  * 對右偏（長尾）分佈資料取 $\log(X)$，壓縮極大值尺度，使分佈更接近常態分佈，穩定變異數。
* **Box-Cox 轉換**：
  * 參數化冪次轉換，透過最大似然估計尋求最佳參數 $\lambda$，將非正態連續資料轉換為近似常態分佈。
* **三大特徵縮放 (Feature Scaling) 方法比較** [🎯 必考選型]：
  * **Min-Max 歸一化 (Normalization)**：
    $$X' = \frac{X - X_{\min}}{X_{\max} - X_{\min}} \in [0, 1]$$
    * 缺點：**極易受極端離群值影響**（單一極大值會將其餘正常資料壓縮在極狹窄區間）；若有新資料超出原始邊界會產生截斷問題。
  * **Z-score 標準化 (Standardization)**：
    $$Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$$
    * 將特徵轉換為均值為 0、標準差為 1 的分佈；但因 $\mu$ 與 $\sigma$ 仍受極端值拉動，面對嚴重離群值時仍會偏移。
  * **穩健縮放 (Robust Scaling)** [🎯 離群值首選]：
    $$X_{\text{robust}} = \frac{X - \text{Median}(X)}{\text{IQR}} = \frac{X - Q_2}{Q_3 - Q_1}$$
    * **核心優勢**：改用對極端值不敏感的**中位數 (Median)** 與**四分位距 (IQR)** 進行中心化與縮放。**當特徵資料中存在極端離群值 (Outliers) 時，Robust Scaling 比 Min-Max 或 Z-score 更適合且更具穩健性**。
* **近似分位數 (Approximate Quantile) 與 分位數回歸 (Quantile Regression)** [🎯 進階必考]：
  * **近似分位數 (Approximate Quantile)**：在巨量資料或高頻串流（如 Spark `approxQuantile`）環境下，精確計算分位數需對全量資料排序，耗費極大記憶體與 I/O；近似分位數演算法能在**可容忍誤差 ($\epsilon$) 範圍內，以極低記憶體開銷快速估算高頻串流資料的分位值**（如即時監控 P95 / P99 延遲）。
  * **分位數回歸 (Quantile Regression)**：傳統最小平方法 (OLS) 僅估計條件平均數且易受離群值干擾；分位數回歸則能**聚焦於特定分位數或尾部分位 (Tail Quantiles，如第 90、99 百分位)**，專門用於**評估極端風險（如金融極端損失、醫療高風險群），且不受常態分佈假設限制**。

### 2. 相關性分析、PCA 標準化必要性與高維分群邊界
* **皮爾森相關係數 (Pearson Correlation, $r$)**：
  * 衡量兩連續變數間之**線性關聯強度**，數值介於 $[-1, +1]$。
  * $r = 1$：完全正線性相關；$r = -1$：完全負線性相關；$r = 0$：無線性相關（但可能存在非線性關係）。
* **主成分分析 (PCA, Principal Component Analysis)** [🎯 常考]：
  * **無監督學習 (Unsupervised)** 降維技術。
  * 尋找使投影後**資料變異數最大化 (Maximize Variance)** 的正交軸（主成分）。
  * 核心價值：消除多重共線性 (Multicollinearity)、降低特徵維度以緩解維度災難、節省運算資源。
  * **為什麼執行 PCA 降維前必須先進行「標準化 (Standardization)」？** [🎯 高頻必考原因]：
    * 由於 PCA 是以「共變異數矩陣」尋求最大化變異數的方向，當輸入變數的**數值量級差異極大**（例如欄位 A 數量級為 $10^5$、欄位 B 數量級為 $10^1$）時，若未先進行標準化，量級為 $10^5$ 的變數其變異數會比 $10^1$ 的變數大上 $10^8$ 倍，導致**第一主成分 (PC1) 幾乎完全被量級最大的欄位所主導**，造成嚴重的特徵偏誤！
* **DBSCAN 密度分群於高維度空間失效的原因** [🎯 演算法邊界考點]：
  * DBSCAN 透過半徑 $\varepsilon$ (Epsilon) 鄰域內的最小點數 ($\text{MinPts}$) 定義高密度核心點，能有效識別任意形狀群集並過濾雜訊。
  * 然而，當**資料維度極高（例如 $>500$ 維）**時，受高維空間稀疏化與距離集中效應（Curse of Dimensionality）影響，**空間中任意兩點的距離變化趨同，導致 $\varepsilon$ (Epsilon) 鄰域閾值選擇失效**，使得**所有資料點極易被誤判為雜訊 (Noise)** 或全部坍縮為單一群集（實務上需先以 PCA 或 Autoencoder 降維後再執行 DBSCAN）。

## 📌 L22302 常見的大數據分析方法與核心演算法

### 1. 關聯規則挖掘 (Association Rules) 與三大指標 [🎯 計算必考]

假設交易資料集中，買了商品 $A$ 也買商品 $B$ 的規則記為 $A \rightarrow B$：

| 指標名稱 | 統計意涵與公式 | 解讀門檻與判斷準則 |
|---|---|---|
| **支援度 (Support)** | $A$ 與 $B$ 同時出現在同一筆交易中的機率：<br/>$$\text{Support}(A \rightarrow B) = P(A \cap B) = \frac{\text{同時含 } A, B \text{ 的交易數}}{\text{總交易數}}$$ | 衡量規則的「普遍性/重要性」。若支援度太低代表為罕見偶然事件。 |
| **信賴度 / 置信度 (Confidence)** | 在購買 $A$ 的前提條件下，同時購買 $B$ 的條件機率：<br/>$$\text{Confidence}(A \rightarrow B) = P(B \mid A) = \frac{P(A \cap B)}{P(A)}$$ | 衡量規則的「可靠性/準確度」。 |
| **提升度 (Lift)** | 購買 $A$ 對購買 $B$ 的促進倍數：<br/>$$\text{Lift}(A \rightarrow B) = \frac{\text{Confidence}(A \rightarrow B)}{P(B)} = \frac{P(A \cap B)}{P(A) \times P(B)}$$ | 衡量關聯的「實質有效性」：<br/>• **$\text{Lift} > 1$**：正向促進關聯（推薦有效）。<br/>• **$\text{Lift} = 1$**：兩者獨立無關。<br/>• **$\text{Lift} < 1$**：負向排斥關聯（互斥）。 |

### 2. 不平衡資料集 (Imbalanced Data) 處理策略 [🎯 常考]
* **欠採樣 (Undersampling)**：隨機剔除多數類樣本。缺點：可能遺失多數類的關鍵代表性資訊。
* **過採樣 (Oversampling)**：隨機複製少數類樣本。缺點：容易導致模型對少數類產生**過擬合**。
* **SMOTE (Synthetic Minority Over-sampling Technique)** [🎯 必考]：
  * **運作機制**：在特徵空間中，對少數類樣本利用其 $K$ 近鄰進行線性插值，**合成生成全新且具多樣性的少數類虛擬樣本**，避免單純複製造成的過擬合。
* **代價敏感學習 (Cost-Sensitive Learning)**：在損失函數中賦予少數類更高的誤判懲罰權重。

### 3. [⚠ 勘誤] 分類模型評估指標與混淆矩陣 (Confusion Matrix) [🎯 計算必考]

| 真實狀況 \ 模型預測 | 預測為正類 (Positive) | 預測為負類 (Negative) |
|---|---|---|
| **實際為正類 (Actual Positive)** | **TP (True Positive, 真陽性)** | **FN (False Negative, 偽陰性/漏報)** |
| **實際為負類 (Actual Negative)** | **FP (False Positive, 偽陽性/誤報)** | **TN (True Negative, 真陰性)** |

#### 四大核心評估指標公式：
1. **準確率 (Accuracy)**：
   $$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$
   * *限制*：在高度不平衡資料下（如信用卡詐欺僅佔 0.1%），無腦全猜負類即可達 99.9% 準確率，指標失去鑑別度。
2. **精確率 (Precision, 查準率)**：
   $$\text{Precision} = \frac{TP}{TP + FP}$$
   * 意涵：預測為正類的所有案例中，實際上真正為正類的比例（防誤報）。
3. **[⚠ 勘誤] 召回率 (Recall, 查全率 / 敏感度 Sensitivity)**：
   $$\text{Recall} = \frac{TP}{TP + FN}$$
   * *(勘誤重點：指引 P.5-21 更正分母嚴格為 $TP + FN$，原誤植為 $TP + FP$)*。
   * 意涵：所有實際為正類的案例中，成功被模型揪出來的比例（防漏報）。
4. **F1-分數 (F1-Score)**：
   $$F_1 = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2TP}{2TP + FP + FN}$$
   * 意涵：Precision 與 Recall 之調和平均數 (Harmonic Mean)，專門評估不平衡資料集之綜合表現。

#### ROC 曲線與 AUC 指標：
* **ROC 曲線 (Receiver Operating Characteristic)**：
  * 橫軸為 **FPR (偽陽性率)**：$FPR = \frac{FP}{FP + TN}$ (負類被誤判為正類的比例)。
  * 縱軸為 **TPR (真陽性率 / Recall)**：$TPR = \frac{TP}{TP + FN}$。
* **AUC (Area Under Curve)**：ROC 曲線下方的面積，取值於 $[0.5, 1.0]$。$\text{AUC} = 0.5$ 代表隨機瞎猜；$\text{AUC} = 1.0$ 代表完美分類器。

## 📌 L22303 數據可視化工具與設計原則

### 1. 常見統計圖表選型對照表

| 圖表類型 | 核心表達目的 | 經典適用場景 |
|---|---|---|
| **散佈圖 (Scatter Plot)** | 呈現兩連續變數之間的相關性與分佈趨勢 | 身高 vs 體重相關性、PCA 降維視覺化 |
| **折線圖 (Line Chart)** | 呈現數值隨連續維度（特別是**時間序列**）之變化趨勢 | 每月營收趨勢、伺服器 CPU 使用率即時監控 |
| **長條圖 (Bar Chart)** | 比較離散類別之間的數值大小差異 | 各部門業績比較、各產品銷量排行 |
| **直方圖 (Histogram)** | 連續數值變數的次數分佈形態（查看是否常態或偏態） | 客戶年齡分佈、考試成績分佈 |
| **箱形圖 (Box Plot)** | 展現資料的集中趨勢、離散寬度 (IQR) 與快速標示離群值 | 不同門市營收之分佈與異常值對比 |
| **熱力圖 (Heatmap)** | 二維矩陣間的高密度數值強度或特徵間相關性大小 | **特徵相關係數矩陣 (Correlation Matrix)** |

### 2. Edward Tufte 的數據密度 (Data Density) 與視覺化設計原則 [🎯 常考情境]
* **核心理念**：資訊視覺化大師 Edward Tufte 強調最大化**數據密度 (Data Density)** 與**資料墨水比 (Data-Ink Ratio)**，追求在**單一圖表中高效率、清晰地傳達多維度資訊**，並剔除無助於理解數據的多餘裝飾（視覺雜訊 Chartjunk，如過度複雜的 3D 立體陰影、花俏格線）。
* **標準實務作法**：當需要同時分析多個產品線在不同地區隨時間的變化時，最佳實踐是**使用不同顏色區分產品線，於同一張圖表中整合多區域趨勢線，保持座標軸比例一致並簡化視覺雜訊**，讓決策者能在單一視野內直接進行跨維度比較。

## 🧮 歷屆核心計算題範例精解

### 範例 1：關聯規則三大指標計算
> **題目**：某超商共記錄 1000 筆購物交易。其中有 200 筆購買了「咖啡」，300 筆購買了「麵包」，有 100 筆同時購買了「咖啡」與「麵包」。請問規則 $\text{咖啡} \rightarrow \text{麵包}$ 的支援度、信賴度與提升度分別為何？
* **解析**：
  1. $\text{Support}(\text{咖啡} \rightarrow \text{麵包}) = \frac{100}{1000} = 0.10 \; (10\%)$
  2. $\text{Confidence}(\text{咖啡} \rightarrow \text{麵包}) = \frac{100}{200} = 0.50 \; (50\%)$
  3. $P(\text{麵包}) = \frac{300}{1000} = 0.30$
  4. $\text{Lift}(\text{咖啡} \rightarrow \text{麵包}) = \frac{\text{Confidence}}{P(\text{麵包})} = \frac{0.50}{0.30} \approx 1.67$
  5. **結論**：提升度 $1.67 > 1$，表示購買咖啡對購買麵包具有顯著的正向促進效應！

### 範例 2：混淆矩陣與各指標計算
> **題目**：某醫療 AI 篩檢系統對 100 位受檢者進行疾病預測，實際與預測混淆矩陣如下：  
> • $TP = 20$（實際有病，預測有病）  
> • $FN = 5$（實際有病，預測沒病）  
> • $FP = 10$（實際沒病，預測有病）  
> • $TN = 65$（實際沒病，預測沒病）  
> 請計算該系統的準確率、精確率、召回率與 F1-score。
* **解析**：
  1. $\text{Accuracy} = \frac{TP + TN}{100} = \frac{20 + 65}{100} = 0.85 \; (85\%)$
  2. $\text{Precision} = \frac{TP}{TP + FP} = \frac{20}{20 + 10} = \frac{20}{30} \approx 0.667 \; (66.7\%)$
  3. $\text{Recall} = \frac{TP}{TP + FN} = \frac{20}{20 + 5} = \frac{20}{25} = 0.80 \; (80\%)$
  4. $F_1 = \frac{2 \times 0.667 \times 0.80}{0.667 + 0.80} = \frac{1.067}{1.467} \approx 0.727$

## 💡 考前精華速記 (L223)

1. **對數轉換與穩健縮放 (Robust Scaling)**：右偏長尾資料用**對數轉換**；特徵含極端離群值時，應優先採用以中位數與 IQR 為基礎的 **Robust Scaling**（優於 Min-Max 與 Z-score）。
2. **近似分位數與分位數回歸**：**近似分位數**可在可容忍誤差內快速估算高頻串流分位值；**分位數回歸**聚焦於尾部分位 (Tail Quantiles)，用於評估極端風險且不受常態分佈假設限制。
3. **PCA 降維前必須標準化**：當變數數值量級差異極大（如 $10^5$ vs $10^1$）時，未標準化會導致**第一主成分 (PC1) 幾乎完全被量級最大的欄位所主導**。
4. **DBSCAN 於高維度失效原因**：當維度極高（$>500$ 維）時，空間距離變化趨同，導致 **$\varepsilon$ (Epsilon) 鄰域閾值選擇失效**，所有資料點易被誤判為雜訊。
5. **Edward Tufte 數據密度原則**：追求單一圖表高效率傳達多維資訊（如用顏色區分產品線、整合多區域趨勢線、保持比例一致並簡化視覺雜訊）。
6. **Seaborn 實戰必考語法**：多區銷量總和用 `sns.barplot(x="variable", y="value", data=pd.melt(df, ...), estimator=sum)`；取前 5 名用 `sns.barplot(x="Name", y="NA_Sales", data=data.nlargest(5, "NA_Sales"))`。
7. **提升度 (Lift) 意義**：$\text{Lift} > 1$ 促銷推薦有效；$\text{Lift} = 1$ 兩商品獨立；$\text{Lift} < 1$ 負相關互斥。
8. **SMOTE 核心技術**：利用少數類樣本的 $K$ 近鄰進行線性插值生成**新虛擬樣本**，避免單純過採樣的過擬合。
9. **Recall 公式 [⚠ 勘誤] 與 ROC 軸**：$\text{Recall} = \frac{TP}{TP + FN}$；ROC 橫軸為偽陽性率 ($FPR$)，縱軸為真陽性率 ($TPR = \text{Recall}$)。
10. **相關係數矩陣與趨勢圖首選**：多特徵相關程度首選 **熱力圖 (Heatmap)**；時間序列趨勢變化首選 **折線圖 (Line Chart)**。
