## 📌 L21101 自然語言處理技術與應用 (NLP)

### 1. NLP 核心發展與技術演進
* **文字預處理 (Preprocessing)**：斷詞/詞元化 (Tokenization)、去除停用詞 (Stop words removal)、詞幹提取 (Stemming)、詞形還原 (Lemmatization)。
* **詞嵌入 (Word Embedding)**：
  * **One-Hot Encoding**：維度災難、無法表達語意相似度。
  * **TF-IDF (詞頻-逆向文件頻率)**：衡量某單詞對語料庫中特定文件的重要程度。
  * **Word2Vec (CBOW / Skip-gram)**：分散式語意表示，捕捉上下文語義關聯。
* **語言模型架構演進**：
  * **RNN / LSTM / GRU**：處理序列資料，但存在長距離依賴消失 (Vanishing Gradient) 與無法平行運算的缺點。
  * **Transformer**：基於**自注意力機制 (Self-Attention)**，實現高度平行化運算，徹底取代傳統循環架構。
  * **BERT (Bidirectional Encoder Representations from Transformers)**：
    * **雙向編碼器 (Encoder-only)**，能同時理解上下文資訊。
    * 預訓練任務：遮罩語言模型 (Masked LM, MLM) 與 下一句預測 (NSP)。
    * 擅長：文本分類、命名實體辨識 (NER)、問答系統 (QA)。
  * **GPT (Generative Pre-trained Transformer)**：
    * **自回歸解碼器 (Decoder-only)**，由左至右單向預測下一個 Token。
    * 擅長：自由文本生成、摘要、對話。

### 2. [⚠ 勘誤] TF-IDF 計算公式與數值示範
* **公式定義**：
  $$\text{TF}(t, d) = \frac{\text{詞 } t \text{ 在文件 } d \text{ 中出現的次數}}{\text{文件 } d \text{ 的總詞數}}$$
  $$\text{IDF}(t, D) = \log_{10}\left(\frac{\text{語料庫總文件數 } |D|}{\text{包含詞 } t \text{ 的文件數 } + 1}\right)$$
  $$\text{TF-IDF}(t, d, D) = \text{TF}(t, d) \times \text{IDF}(t, D)$$
* **[⚠ 勘誤重點]**：指引 P.3-18 勘誤：若總文件數 $|D| = 1000$，包含 "AI" 的文件數為 $10$：
  $$\text{IDF}(\text{"AI"}, D) = \log_{10}\left(\frac{1000}{10}\right) = \log_{10}(100) = 2$$
  *(原誤植為 $\approx 2$，官方勘誤修正為嚴格等於 $2$)*。

### 3. [🎯 常考] NLP 典型應用場景
* **文本分類與情感分析**：電商評論正/負面情緒判定、社群輿情危機即時監控。
* **命名實體識別 (NER)**：由非結構化文本中抽取人名、地名、組織名、日期。
* **FAQ 智慧客服 (Chatbot)**：檢索式 vs 生成式；若上線後未持續再訓練與微調，容易出現錯誤回覆與幻覺。

## 📌 L21102 電腦視覺技術與應用 (CV)

### 1. 核心任務層級劃分 [🎯 常考極高頻]

| 任務名稱 | 核心目標 | 輸出形式 | 典型代表模型 |
|---|---|---|---|
| **影像分類 (Classification)** | 判斷「整張圖片是什麼」 | 單一或多個類別標籤 | ResNet, VGG, MobileNet |
| **物件偵測 (Object Detection)** | 辨識「目標在哪裡」並「是什麼」 | **類別標籤 + 矩形邊界框 (Bounding Box)** | YOLO, SSD (單階段); Faster R-CNN (雙階段) |
| **語意分割 (Semantic Segmentation)** | 區分「每個像素屬於什麼類別」 | 像素級類別遮罩 (同一類像素同色，**不區分個體**) | U-Net, DeepLabV3, FCN |
| **實例分割 (Instance Segmentation)** | 區分每個像素，並**區分不同個體** | **像素級遮罩 + 個體辨識** (貓A與貓B著不同色) | Mask R-CNN |

### 2. 卷積神經網路 (CNN) 關鍵機制
* **卷積層 (Convolutional Layer)**：利用卷積核 (Filter/Kernel) 提取局部空間特徵（邊緣、紋理、形狀）。具有**權重共享 (Weight Sharing)** 與**平移不變性 (Translation Invariance)**。
* **池化層 (Pooling Layer)**：降維以減少參數量、防止過擬合（常用 Max Pooling 或 Average Pooling）。
* **全連接層 (Fully Connected Layer)**：整合高維特徵並輸出最終分類機率。
* **資料增強 (Data Augmentation)**：翻轉、旋轉、裁剪、色彩抖動，提升模型泛化能力。

### 3. 工業與醫療實務案例
* **工業瑕疵檢測 (AOI + AI)**：表面刮痕、焊點不良；需搭配**即時回饋機制**，在檢測出異常時立即通知產線調整。
* **醫療影像輔助診斷**：X-ray、CT 斷層掃描病灶分割，要求高召回率 (High Recall) 避免漏診。

## 📌 L21103 生成式 AI 技術與應用 (GenAI)

### 1. 主流生成模型技術架構比較

| 模型架構 | 原理機制 | 優點 | 缺點 / 限制 |
|---|---|---|---|
| **GAN (生成對抗網路)** | **生成器 (Generator)** 與 **鑑別器 (Discriminator)** 進行博弈訓練 (Minimax Game) | 生成影像清晰度高、細節銳利 | 訓練不穩定、容易發生**模式崩潰 (Mode Collapse)** |
| **VAE (變分自動編碼器)** | 將輸入編碼為潛在空間機率分佈 (均值 $\mu$、方差 $\sigma^2$)，再解碼採樣 | 數學理論嚴謹、潛在空間連續易插值 | 生成影像相對模糊 (Blurry) |
| **Diffusion (擴散模型)** | **前向過程 (Forward Process)** 逐步加入高斯噪聲；**反向過程 (Reverse Process)** 學習逐步去噪復原 | 生成多樣性高、訓練穩定不易崩潰 | 推論 (Inference) 需多步迭代，運算耗時較長 |
| **LLM (大語言模型)** | 基於 Transformer 解碼器之自回歸文字接龍 | 強大上下文理解、少樣本 (Few-shot) 與推理能力 | **模型幻覺 (Hallucination)**、知識截斷、運算成本高昂 |

### 2. 企業級 LLM 優化關鍵手段
* **提示工程 (Prompt Engineering)**：
  * **Zero-shot / Few-shot**：直接給指示或附帶少量範例。
  * **CoT (Chain-of-Thought, 思維鏈)**：引導模型「一步步推導」，大幅提昇邏輯運算與多步驟問題的準確率。
* **RAG (檢索增強生成, Retrieval-Augmented Generation)** [🎯 常考]：
  * **運作流程**：使用者提問 $\rightarrow$ 向量化 (Embedding) $\rightarrow$ 向量資料庫相似度檢索 (Vector Search) $\rightarrow$ 提取相關知識文本注入 Prompt 上下文 $\rightarrow$ LLM 生成具事實依據之回答。
  * **核心價值**：有效抑制幻覺、解決知識時效性 (即時更新企業私有庫)、無須負擔龐大微調成本。
* **微調 (Fine-Tuning / PEFT)**：
  * 適用於特定領域專業語境、固定輸出結構需求。常用 **LoRA** (Low-Rank Adaptation) 降低參數量與硬體門檻。

## 📌 L21104 多模態人工智慧應用 (Multimodal AI)

### 1. 多模態核心架構與概念
* **多模態融合 (Multimodal Fusion)**：
  * **前期融合 (Early Fusion / Feature-level)**：在特徵輸入階段拼接多模態特徵。
  * **後期融合 (Late Fusion / Decision-level)**：各模態獨立輸出預測結果後進行加權或集成。
* **CLIP (Contrastive Language-Image Pre-training)** [🎯 常考]：
  * 透過**對比學習 (Contrastive Learning)**，將圖像編碼器 (Image Encoder) 與文字編碼器 (Text Encoder) 投影到相同的共享語意向量空間。
  * 支援 **Zero-shot 影像分類** 與跨模態圖文檢索。
* **典型多模態應用**：
  * 文字生圖 / 文字生影 (Text-to-Image / Text-to-Video)：Stable Diffusion, Midjourney, Sora。
  * 圖文問答 (VQA)：GPT-4o, Gemini 具備視覺理解與問答能力。
  * 智慧語音：ASR (語音轉文字) + LLM 處理 + TTS (文字轉語音)。

## 💡 考前 10 句精華速記 (L211)

1. **TF-IDF 計算**：$\text{IDF} = \log_{10}(|D|/df)$，若總數 1000 篇、出現 10 篇，則 $\text{IDF} = \log_{10}(100) = 2$。
2. **BERT vs GPT**：BERT 是雙向 Encoder（做分類/理解/NER）；GPT 是單向自回歸 Decoder（做生成/摘要/對話）。
3. **物件偵測輸出**：必須包含**物件類別**與**邊界框 (Bounding Box)**；代表模型為 YOLO、Faster R-CNN。
4. **語意分割 vs 實例分割**：語意分割只分像素類別不分個體；實例分割**既分像素又分獨立個體**（如區分貓A與貓B）。
5. **GAN 核心痛點**：生成器與判別器博弈，最常遇到**模式崩潰 (Mode Collapse)** 與訓練不穩定。
6. **擴散模型 (Diffusion)**：包含前向加噪與反向去噪，生成品質高且多樣，但反向推論多步迭代導致耗時長。
7. **RAG 核心目標**：檢索私有或即時外部資料注入 Prompt，是企業低成本解決**模型幻覺**與知識過期的首選技術。
8. **思維鏈 (CoT)**：引導 LLM 輸出推導步驟（Let's think step by step），顯著提升複雜邏輯與數學推理正確率。
9. **CLIP 核心價值**：利用對比學習將圖片與文字映射至**統一共享向量空間**，實現優異的 Zero-shot 分類與跨模態搜尋。
10. **AOI 製造瑕疵檢測**：電腦視覺落地需整合**即時回饋機制**，一旦偵測到缺陷立即回報調整產線。
