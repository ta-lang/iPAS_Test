## 📌 L12201 數位化企業新興智慧資訊技術

### 1. 雲端運算三大服務模式 (Cloud Computing Models)

```
+--------------------------------------------------------------+
| SaaS (軟體即服務): Salesforce, Google Workspace, Office 365    |
| (終端使用者直接在瀏覽器操作完整應用軟體，無需管理底層)       |
+--------------------------------------------------------------+
                               ▲
+--------------------------------------------------------------+
| PaaS (平台即服務): Google App Engine, AWS Elastic Beanstalk   |
| (開發者專注於應用程式開發與部署，雲端託管作業系統與中介軟體)  |
+--------------------------------------------------------------+
                               ▲
+--------------------------------------------------------------+
| IaaS (基礎設施即服務): AWS EC2, GCP Compute Engine, Azure VM  |
| (提供純虛擬化運算、儲存與網路資源，企業需自行安裝維護作業系統)|
+--------------------------------------------------------------+
```

| 服務模式 | 全名 | 企業掌控範疇 | 雲端服務商 (CSP) 負責範疇 | 企業適用情境 |
|---|---|---|---|---|
| **IaaS** | Infrastructure as a Service | 作業系統 (OS)、中介軟體、Runtime、應用程式、資料庫 | 實體伺服器硬體、機房散熱、電力、虛擬化 Hypervisor、實體網路 | 具備專業 IT 維運團隊，需要底層客製控制權 |
| **PaaS** | Platform as a Service | 應用程式代碼 (Application)、資料模型 (Data) | 作業系統更新補丁、程式執行環境 (Runtime)、資料庫底層、伺服器自動擴展 | 軟體研發團隊專注開發與快速原型上線 |
| **SaaS** | Software as a Service | 僅使用者存取帳號與應用層組態設定 | 全包（涵蓋底層硬體至頂層軟體功能升級與維護） | 企業直接導入成熟標準流程，避免重複造輪子 |

### 2. 物聯網 (IoT) 與射頻識別 (RFID)
* **物聯網 (IoT, Internet of Things)**：透過感測器（Sensors）、通訊模組與邊緣設備，將實體物件聯網，收集環境、震動、溫度等動態數據。
* **射頻識別 (RFID, Radio-Frequency Identification)**：
  * **被動式 RFID (Passive Tag)**：無內建電池，靠讀卡機發出的電磁波感應驅動。成本極低、體積小、讀取距離較短（數公分至數公尺）。常見於悠遊卡、商品防盜扣、倉儲棧板標籤。
  * **主動式 RFID (Active Tag)**：內建電池主動發射訊號，傳輸距離遠（可達上百公尺）、訊號穿透力強但成本較高。常見於貨櫃追蹤、高價值車輛管理。
  * **條碼 (Barcode) vs RFID 對比**：RFID 無需光學直視（Non-line-of-sight）、可穿透包裝同時批次讀取數百個標籤，大幅革新物流盤點效率。

### 3. 大數據 5V 特性矩陣

| 特性名稱 | 英文 | 核心內涵 | 技術挑戰與應對 |
|---|---|---|---|
| **大量性** | Volume | 數據量達到 TB、PB 甚至 EB 等級 | 分散式儲存與運算（Hadoop HDFS, 云端物件儲存 S3） |
| **多樣性** | Variety | 結構化、半結構化（JSON/XML）與非結構化（影音/文字）並存 | 現代資料湖 (Data Lake) 架構、多模態資料整合 |
| **高速性** | Velocity | 數據產生與流通速度極快，具備即時串流屬性 | 串流計算引擎 (Apache Spark Streaming, Flink)、記憶體內快取 |
| **真實性** | Veracity | 數據品質參差不齊，充滿雜訊、遺失值與不確定性 | 資料治理、資料清洗與品質監控管道 |
| **價值性** | Value | 單位數據價值密度低，但經由演算法提煉後具備龐大商業價值 | 資料探勘、機器學習預測與營運優化 |

## 📌 L12202 企業營運常見資訊系統

### 1. 企業六大營運資訊系統全方位對照矩陣

| 系統簡稱 | 全域名稱 | 核心管理標的與焦點 | 主要功能模組與應用 | 系統為企業帶來的核心價值 |
|---|---|---|---|---|
| **ERP** | 企業資源規劃系統 (Enterprise Resource Planning) | 企業內部的「**人、事、物、錢**」核心資源整合 | 總帳財務、生產製造、採購進貨、銷售接單、庫存核算 | 打破部門資訊孤島，落實單一事實來源 (Single Source of Truth) |
| **SCM** | 供應鏈管理系統 (Supply Chain Management) | 跨企業「**從供應商到最終客戶**」的物料與資訊流通 | 需求預測、供應鏈排程、物流配送追蹤、跨組織協同 | 縮短交期、降低安全庫存，化解「長鞭效應 (Bullwhip Effect)」 |
| **CRM** | 客戶關係管理系統 (Customer Relationship Management) | **客戶生命週期管理**（獲客、留客、再行銷） | 潛在商機追蹤、行銷自動化、客服客訴工單系統、RFM 會員分群 | 提升顧客終身價值 (LTV)、降低客戶流失率與獲客成本 |
| **PLM** | 產品生命週期管理系統 (Product Lifecycle Management) | 產品「**從概念發想、研發設計到除役報廢**」全流程 | CAD/CAM 圖檔管理、物料清單 (BOM) 版本控管、設計變更管理 | 加速新產品上市時間 (Time to Market)、確保工程變更追溯性 |
| **KM** | 知識管理系統 (Knowledge Management) | 企業內部**隱性與顯性知識**之沉澱與傳承 | 知識庫檢索、專家目錄、最佳實踐 (Best Practice) 分享 | 避免關鍵人員離職造成技術斷層，促進組織持續創新 |
| **RPA** | 機器人流程自動化 (Robotic Process Automation) | 模擬人類在電腦上的**高重複性、規則明確之日常事務** | 跨系統資料轉打、發票對帳核銷、電子郵件附件批次抓取 | 7x24 不間斷運作、降低人為鍵入失誤、釋放員工從事高價值工作 |

---

### 2. SCM 供應鏈推式 (Push) vs 拉式 (Pull) 策略對比

| 比較維度 | 推式供應鏈 (Push-based / Make-to-Stock) | 拉式供應鏈 (Pull-based / Make-to-Order) |
|---|---|---|
| **驅動源頭** | 依據**歷史預測 (Forecast-driven)** | 依據**實際顧客訂單 (Demand-driven)** |
| **生產模式** | 計畫性生產（預先製造備貨） | 接單後生產（無訂單不投產） |
| **優點** | 規模經濟生產、現貨供應立即滿足客戶 | 零庫存或極低庫存風險、高度客製化彈性 |
| **缺點** | 預測失誤引發庫存滯銷或嚴重缺貨，易產生長鞭效應 | 前置時間 (Lead time) 較長，無法應對突發性巨量訂單 |
| **混合模式** | **推拉邊界策略 (Push-Pull Boundary)**：前端通用零組件採推式預先生產，後端組裝採拉式延遲策略 (Postponement)。 |

## 📌 L12203 數位化轉型創新與價值創造

### 1. 企業流程再造 (Business Process Reengineering, BPR)
由 Michael Hammer 與 James Champy 提出，其核心定義為：
「針對企業的業務流程進行**根本性 (Fundamental)** 的重新思考，以及**徹底性 (Radical)** 的翻新設計，以期在成本、品質、服務與速度等攸關績效的關鍵指標上，獲得**顯著性 (Dramatic)** 的躍進改善，並以**流程 (Processes)** 為核心導向。」

#### BPR 四大關鍵字精解：
1. **根本的 (Fundamental)**：捫心自問企業「為什麼要這麼做？」，揚棄盲目遵循的舊慣例。
2. **徹底的 (Radical)**：非細枝末節的修修補補，而是從根拔起重新發明全新運作方式。
3. **顯著的 (Dramatic)**：追求數倍乃至數量級的突破（如流程時間縮短 80%），而非 5%~10% 的漸進式改善。
4. **流程導向 (Process-oriented)**：打破傳統職能部門分工的藩籬，轉以端到端（End-to-End）為核心。

---

### 2. 波特價值鏈模型 (Porter's Value Chain)
企業創造利潤與競爭優勢的九大互相關聯活動：

```
+--------------------------------------------------------------+
| 支援活動 (Support Activities):                                 |
| 1. 企業基礎設施 (Firm Infrastructure)                           |
| 2. 人力資源管理 (Human Resource Management)                    |
| 3. 技術研發 (Technology Development)                          |
| 4. 採購管理 (Procurement)                                     |
+--------------------------------------------------------------+
                               ▲
+--------------------------------------------------------------+
| 主要活動 (Primary Activities):                                 |
| [內部物流] ─▶ [生產作業] ─▶ [外部物流] ─▶ [行銷與銷售] ─▶ [售後服務]  |
+--------------------------------------------------------------+
                                                                =======> 利潤 (Margin)
```

1. **主要活動 (Primary Activities)**（直接參與產品實體流轉與交付）：
   * **內部物流 (Inbound Logistics)**：原物料接收、倉儲管理與內部派送。
   * **生產作業 (Operations)**：將原料轉化為最終成品的機械加工與組裝。
   * **外部物流 (Outbound Logistics)**：最終成品的倉儲、包裝與出貨分銷。
   * **行銷與銷售 (Marketing & Sales)**：廣告、通路定價與促銷活動。
   * **售後服務 (Service)**：安裝調試、保固維修與顧客投訴處理。
2. **支援活動 (Support Activities)**（為主要活動提供基礎支撐）：
   * 採購、技術發展（研發）、人力資源管理、企業基礎制度（財務/法務/高層管理）。

---

### 3. 數位轉型三大層次演進
1. **數位化 (Digitization)**：資訊由實體紙本轉為數位格式（如紙本發票掃描建檔為 PDF/系統欄位）。
2. **數位優化 (Digitalization)**：運用數位科技改善既有業務流程與營運效率（如引進 RPA 自動審核報銷單）。
3. **數位轉型 (Digital Transformation)**：全面重構企業商業模式、文化與價值主張，開創全新數位營收生態（如製造業從賣硬體設備轉型為賣「訂閱制預測維護服務 (Everything-as-a-Service)」）。

### 🎯 考前衝刺「一句話考點」
1. 雲端運算三大層次中，**IaaS** 提供基礎運算與虛擬機；**PaaS** 提供應用執行環境；**SaaS** 為直接透過瀏覽器取用之完整軟體。
2. **被動式 RFID (Passive Tag)** 無需內建電池，靠讀取器無線電波供電感應，成本低廉且廣泛用於物流貨物追蹤。
3. 大數據的 5V 特性分別為：**大量性 (Volume)、多樣性 (Variety)、高速性 (Velocity)、真實性 (Veracity)、價值性 (Value)**。
4. **ERP 系統** 是企業營運的核心中樞，整合跨部門之人、事、物、錢，打破組織資訊孤島。
5. **SCM 系統** 管理由上游供應商至最終消費者的端到端流程，有效抑制因資訊失真造成的「**長鞭效應**」。
6. **PLM 系統** 專注於產品從概念發想、工程研發到報廢全生命週期管理，核心包括圖檔與 BOM 表控管。
7. **RPA (機器人流程自動化)** 專門處理「規則明確、高度重複、跨系統」的日常鍵盤滑鼠事務作業。
8. 企業流程再造 (BPR) 的四大關鍵詞為：**根本的 (Fundamental)、徹底的 (Radical)、顯著的 (Dramatic)、流程 (Process)**。
9. 波特價值鏈將企業活動分為**主要活動**（內/外物流、生產作業、行銷銷售、售後服務）與**支援活動**（採購、研發、人資、基礎設施）。
10. 供應鏈由推式轉為拉式的主要好處是**依實際訂單驅動生產，大幅降低庫存積壓與滯銷風險**。
